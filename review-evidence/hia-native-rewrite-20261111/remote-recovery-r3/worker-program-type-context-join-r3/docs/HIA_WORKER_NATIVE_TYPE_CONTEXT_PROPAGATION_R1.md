## The real issue addressed

The old native type adapter reports broad enum messages. The original public
API supplies contextual labels such as nominal type, field, parameter and loan
origin. A fixed enum catalog cannot supply those labels faithfully.

The type owner records first-error context at its existing private workspace
offset 96 MiB + 192, after real command decoding and in original semantic order.
The small native reader consumes the immutable actual type workspace, the
complete original command header and the actual type return header. It produces
the exact original message from one of 33 context tuples. Neither host nor
parent reconstructs a where label or inserts a message.

The native name check performs the full identifier grammar before testing the
reserved prefix, matching the original _ident then _name order. Mixed malformed
reserved-prefix names consequently preserve the public error5 first error.
This is an explicit semantic correction with old/new component evidence, not a
claim that the old adapter's generic text was already correct.

## Immutable result and ordering

The reader result is 128 bytes followed by the complete ASCII error text.
Its sixteen little-endian u64 words are:

| Word | Value |
|---|---|
| 0 | HIATDE01 |
| 1 | Version 1 |
| 2 | Actual type session lease |
| 3 | Actual completed command sequence |
| 4 | Actual caller request |
| 5 | Type operation, 1 through 6 |
| 6 | Error, 1, 5 or 6 |
| 7 | Context where |
| 8 | Context inventory mask |
| 9 | Actual source node offset, or the permitted missing-node sentinel |
| 10 | Complete text bytes |
| 11 | Total extent, 128 plus text bytes |
| 12–14 | Actual cached, active and step counters |
| 15 | Zero |

Actual source node offsets are checked against the original typed packet
regions and 56-byte node alignment. The exact where/error/mask tuple determines
the required text length. Counter overflow, invalid extent, reserved values or
a wrong lease/request/error are private ABI failures.

Role41 captures context after the actual types call and the actual validator
REPLY, before any type cleanup. A reader GROW repeats only the stateless reader
on the same immutable inputs. It does not repeat types or validator REPLY.
The existing constructor response and failed-init cleanup order remain after
context completion. Role43 carries the actual capsule into role40; role40
publishes the original terminal only after a fresh header view and validation.

The fixed syscall executor transfers the actual owned readonly slot57
descriptor only for terminal group2/errors1,5,6 at the established mode0/role40
or mode2/role46. It clears the child descriptor before child cleanup. It never
interprets context contents, text or where. The original group8 Core transfer
stays present. Mode/depth/source-kind/pending ACK restrictions are retained.

Role46 validates the actual lower capsule and copies it readonly without
rebinding its header. P16 validates the actual program capsule, copies only its
text into its final result, then releases the capsule before publication.
P16 uses the existing child target6; it does not reuse assembly slots51–58.
The existing enum fallback is retained only when no actual contextual capsule
was issued. Contextual errors are never reformatted by the parent.

The fixed role mask keeps reader50 R/R/W and catalog51 R/W/W. The composition
proof requires exact inverse restoration of all changed assembly text and
preserves every other role's mask bit. The original assembly child-frame
function and expanded assembly-service source must remain byte-identical.
