## Reference correction

The older sequence fixture synthesized a profile SHA from the profile name
but its artifact reference SHA from a different label. That was explicitly a
foreign placeholder; it cannot serve as the oracle for actual Store.profile.

The new Namespace fixture invokes the original methods:

    AgentStore.profile -> AgentStore.json -> original wire -> foreign put
      -> profile value -> original wire(ref).decode()
      -> foreign INSERT OR IGNORE profiles -> (profile, original ref)

For discovery it invokes original AgentStore.json -> original wire -> put.
The fixed SQL remains operation 5, with identifier / reference SHA / exact
reference wire in that order. No transaction, commit, rollback, retry or
namespace publication is invented.

The complete original constructor is run before the native interval. Each
Store method record contains its original arguments, full namespace calls,
method result or exception, and the actual owner partial-state snapshot.
Every namespace result Graph packet or exception payload is captured before
the native interval. Native routing only stamps the actual reserved lease
and moves those declared immutable bytes.

The high-level profile/json observer remains at its historical call point,
after the original method returns. Failure injected at that observer is
therefore separate from a failure of the lower-level put/SQL operation.
