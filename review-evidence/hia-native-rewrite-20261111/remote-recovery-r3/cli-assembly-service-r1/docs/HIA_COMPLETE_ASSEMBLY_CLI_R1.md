# Complete assembly CLI service and publication — development revision 1

This is a new, unexecuted composition. No component's historical case count is
credited to this composition. The actual CI must generate each new HIA image,
compile under the original B3 limits, pack the ELF with the actual HIA packer,
and execute the complete public reference corpus before an execution claim.

## Public actions

The existing argv, file, formatting and error owners remain actual native
components. The parent sends actions 3, 4 and 5 to service table 1.

| Action | Native order | Output |
|---|---|---|
| import-assembly | original file gate; complete assembly syntax; actual object snapshot and structure gate; actual raw/program/primitive admission | complete Core through the original pretty owner, or actual policy 1 publication |
| render-assembly | original file gate; complete program admission; actual renderer; complete new syntax/object/primitive roundtrip; every canonical byte compared | exact assembly text without an extra LF, or actual policy 3 publication |
| check-assembly | original file gate; complete syntax/object/primitive sequence; native complete diagnostic object | original pretty JSON and exit 0 or 1 |

The syntax owner retains one MiB source, 16,384 lines, 16,384 bytes per line,
256 functions, 4,096 blocks, 16,384 operations and 256 list items. These are the
original public frontend limits, not the smaller bootstrap compiler profile.
The renderer receives an actual admitted Core and does not apply those syntax
limits while constructing text. The complete later roundtrip applies them in
the original order.

The syntax output is a complete insertion-order JSON transport issued by this
pipeline. A valid transport is not a Core admission receipt. The object prefix
measures its required transport allocation without an early public raw JSON
budget, performs forward snapshot DFS and queued-node accounting, then the
original reverse structure walk and byte accounting, and only then emits
canonical JSON. It grants no primitive semantic authority.

Only a successful prefix view is copied to a new read-only canonical slot and
sent through the existing actual raw44/program46/ordinary/primitive27 and
diagnostic55 chain. The additional raw transport gate follows the completed
object gates. Its success requirements are restatements of the actual prefix:
canonical bytes at most 8 MiB, value nodes at most 262,144 and original depth
64. Transport container stack depth may be 65 for an empty container at value
depth 64. Syntax integer production already retained its original digit limit.
An unexpected raw/prefix rejection at this point is a private ABI failure,
never rewritten into a public Core refusal.

The actual child receipt, its complete Core extent, native digest and byte
identity are preserved. For rendering, the second admitted Core is compared
against the first admitted Core in complete 256-byte windows, including the
last partial window. Equality is not replaced with a digest-only check.

## Tables, roles and finite contexts

The executable has 140 physical image entries: 14 parent entries and two
independent 63-entry service tables. One A query role is vacant; 139 entries are
nonzero in this composition. The numbers describe layout, not qualification.

| Table | Role | Meaning |
|---|---:|---|
| parent | 7 | public CLI parent and complete filesystem publication continuation |
| parent | 8–14 | verified publication, Path, SHA, buffered staging writer, temporary directory, complete cleanup, presentation |
| A | 56 | original A root with assembly routing and actual publication continuation |
| A | 59 | assembly syntax/object/admission/render/roundtrip continuation |
| A | 60 | unchanged actual HIAPIC01 projector |
| A | 61 | complete syntax, two read-only inputs |
| A | 62 | complete renderer, two read-only inputs |
| A | 63 | object prefix, independent output and workspace writable buffers |
| E | 1–63 | unchanged complete candidate table; inactive dependency |

The fixed composer requires the complete service suffix to equal the retained
finite carrier before applying exactly two changes. Only A may call roles
61–63 and only its controller 59 may do so. Role 60 remains callable only from
56 in A. The A two-read mask becomes 70bf80bee2ac0462; the E mask remains
e0bf80bee2ac0462. Parent filesystem metadata and the program/ordinary child
instruction ranges remain exact.

Every descendant non-edit component call remains limited to 1–28 or exactly
55. Program and ordinary controller ranges, role writes and maximum child
depth remain the original finite graph. No arbitrary recursion is introduced.
The complete 63-image E map is separately bound to Git blob
35202c1c5961923b60f6100e07fa696e2c8f84a0, every source and image is checked, and
the builder asserts all 63 E image bytes are unchanged in the actual packet.
No E process is executed or qualified by this assembly corpus. The partial A75
asset table is not presented as a complete E table.

## State and view lifetimes

Assembly control uses distinct state words beginning at offset 60,000 of the
existing one MiB controller workspace. Compile-time assertions check its new
slots against the existing program, Core, receipt, public result and SHA slots.

| Slot | Contents |
|---:|---|
| 51 | immutable syntax or renderer command |
| 52 | renderer state plus complete text |
| 53 | syntax state plus complete issued document |
| 54 | object-prefix output |
| 55 | object-prefix scratch |
| 56 | copied read-only canonical syntax result |
| 57 | copied read-only actual final admitted Core |
| 58 | complete native assembly diagnostic JSON |

A workspace or result view is protected before being borrowed by another
owner. All GROW retries use the same actual source and command lease. Object
prefix GROW recomputes its pure result; it neither issues a Core nor advances a
registry. The original renderer text remains live while its complete syntax
roundtrip runs. Only the A root issues parent YIELD/RESUME; controller 59
switches back to it with an explicit completion.

The native diagnostic builder preserves the distinction between source
preflight failure, later syntax failure and primitive Core failure. It includes
source bytes/hash only when the whole original source preflight completed.
The complete source and message are hashed/escaped in HIA, including line and
error code. Python is used solely by the independent reference process.

## Actual publication

Policy 1 remains canonical Core publication. Policy 2 and its old parent path
remain unchanged; no E semantic execution is claimed. New policy 3 is valid
only for action 4 in service 1.

Policy 3 follows the original assembly publisher: Path.absolute; reject an
existing target or symlink; recursive parent mkdir; resolve/symlink refusal;
TemporaryDirectory prefix '.hepta-assembly-'; stage 'program.hiaasm'; UTF-8
text without an extra LF; buffered write/flush/fsync/close; actual verified
no-replace publication and its three readbacks; complete temporary cleanup.
The existing native entropy, collision, inode, FD, errno and cleanup owners
are reused. The two new path refusal strings are appended as presentation
codes 19 and 20; old codes retain their numbers.

The parent returns the complete HIACPR01 containing actual destination JSON
and actual publication receipt. The A service checks every correlation and
extent plus exact receipt bytes against the native hash and length of its
rendered text, then emits the complete assembly-output object with the actual
Core hash. Carrier code neither manufactures a receipt nor parses its JSON.

## New validation

The builder keeps full authoring, generated source, profile, B3 receipt,
actual image, packed input, output and fixed assembly. B3 retains 10 CPU
seconds, 20 wall seconds and 256 MiB. Every public native/reference child
retains 90 CPU seconds, 180 wall seconds, one GiB address space, no core,
parent-death signal and finally kill/wait cleanup. Aggregate CI deadlines are
separate from these per-execution limits.

A complete immutable planned corpus is written before the first public native
execution. It includes retained full renderer fixtures, selected syntax-domain
and ordering fixtures, resource and loan errors, exact v6/v7/v8 behavior,
late line/list/function/block/source gates, all three public file gates,
actual policy 1/3 paths, FD zero, filesystem-byte paths, no-replace and
symlink errors. Outputs, error streams, exit codes, created files and their
modes are compared completely against independent CPython 3.12.14 hia_main.
The new corpus does not rerun the old syntax/renderer component suites.

Separate actual-native private controls exercise initial correlation,
SWITCH acknowledgement, controller phase and permanent poison, plus duplicate
GROW acknowledgement. These fixture headers and mutated private states are
not a source-authentication claim. The normal public corpus contains no
foreign runtime semantic callback.

Every complete buffer is stored by SHA with lossless compressed CAS and
read back. Physical fixture objects are recorded before deletion, and failure
paths are retained in the outer CI physical inventory. Successful counts are
derived from the actual terminal summary and must match the planned corpus,
not copied from this document.

Open outside this slice: installed activation, cold qualification, arbitrary
foreign-object capture, nondefault process locale/stdout setup, startup digit
capture, and E's separate public service execution.
