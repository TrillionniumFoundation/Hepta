# Explicit legacy importer: complete native Group9 diagnostic development gate

## Current status

This is a new, inactive development composition. The source has been stored as
Git blobs and read back in full. There has been no Python AST gate, authoring
generation, assembler execution, B3 compilation, HIA entry, ELF case or CI result
for this revision. The exact historical R9 importer and its archived observations
are dependencies; their success is not inherited by this new composition.

The ordinary P16 entry is unchanged. This executable selects the explicit
historical nominal-v2 importer. It does not infer that profile from an ordinary
structured-program request, issue namespace authority, or activate an installed
Worker route.

## Diagnostic ownership and wire contract

The original four semantic failure points are preserved:

| Original phase | Error | Original public message |
| --- | --- | --- |
| 5 | 1 | E_HIA_FORMAT: legacy nominal program: expected exactly functions, module, schema, types |
| 5 | 2 | E_HIA_VERSION_COLLISION: explicit nominal-v2 adapter requires nominal-v2 input |
| 28, after the actual old Core child | 3 | E_HIA_LIMIT: program exceeds byte budget before encoding |
| 31, after the full comparison receipt | 4 | E_HIA_UPGRADE: nominal adapter changed primitive operations/CFG/effects |

The new HIA continuation occupies phases 90000 through 90003. It issues GROW,
COPY and PROTECT for private slot57. It writes the complete message and the
eight little-endian u64 words:

    HIALDE01, 1, 9, error, importer_lease, final_sequence, total_bytes, text_bytes

The total is exactly 64 plus the complete UTF-8 text length. The final sequence
is the same sequence subsequently placed in the unchanged original terminal.
Only the three real mechanical events advance the sequence. All other fifteen
terminal words must match the actual old importer for corresponding private
continuations.

The slot is a readonly, owned result in the actual top-level importer context.
A byte header, Graph ID or private fixture is not an authority token. The driver
abandons a lease after BAD, including the short-workspace case where the kernel
cannot write poison into memory it was not authorized to receive.

The fixed executor has one exact reversible source edit after its original
128-byte terminal write. For actual top-level role46, if slot57 exists, it checks
the actual descriptor's owned/readonly flags, positive logical extent and mapped
extent. It appends the complete logical bytes to stderr. It does not inspect the
diagnostic header, select an error code, format text or reinterpret a child.
All old raw input, child handling, success output, rights masks and cleanup
instructions remain unchanged.

Public process framing:

| Outcome | Exit | stdout | stderr |
| --- | --- | --- | --- |
| Success | 0 | Full canonical object containing Core, report and structured program | Empty |
| Group9 rejection | 2 | Empty | Original terminal128, HIALDE01 header64, full original UTF-8 message |
| Other original rejection | Original behavior | Original behavior | Original behavior |

The executor uses no Python, shell, dynamic loader or external program at
runtime. Public tests run the actual ELF with empty PATH and HOME. This gate does
not claim a syscall trace or installed-product qualification.

For all 22 public cases, the exact original import_legacy_composite_v2 is called

The three large fixtures use valid, unused enum declarations within the original

## First-failure and evidence rules

Every source, image, executable, compiler and reference is bound before use and
checked again after execution. The complete original R9 archive, ledger and all
extracted members are retained. Runtime CAS keeps full bytes, not sampled pages
or only hashes. An entry is logged before calling native code; returned complete
buffers are saved before assertions. A signal/timeout retains pending-entry or
pending-process state.

The build records compile attempts before each B3 invocation. Independent
finalization attempts preserve the earliest exception and any subsequent
cleanup/receipt failures. A partial failure does not receive a success count.
All complete group stdout/stderr/process records and before/after source modes
are included in the final common artifact.

The new source inventory includes the exact old authoring closure, the two new
HIA/executor authors, complete restoration/build/test helpers and an independent
CI driver. Old unexecuted authoring revisions are retained under history and
excluded from the active source inventory. No branch ref, production selector,
test budget or old evidence is modified by this delivery.
