## Native responsibilities

The controller owns exact input-kind rejection, str/bytes UTF-8 and byte-budget order, the complete original HIA integer-only JSON preflight and all its diagnostic reasons, peer continuation validation, complete diagnostic text, and the final owned Graph copy. Actual value construction uses the existing general JSON arena image followed by the independently frozen arena-to-Graph r2 image. There is no hosted parser, integer conversion, diagnostic plan or materializer in the forwarding loop.

## Preserved development history

The first compile harness attempt contained a source-path typo and failed before invoking native compilation; its source freeze, script and failure log are retained. The r1 image then passed the same public differential. Two independent actual private-frame mutations showed that it accepted a success frame with nonzero error-index metadata and a semantic error with an out-of-range arena index. These exact frames, workspaces, source/image pins and accepted outcomes remain in the archive. They are private transport counterexamples, not public JSON acceptance differences.

Revision r2 adds completion/error metadata and arena-count validation plus complete header snapshots across controller GROW. The original parser, diagnostic sequence and accepted public language are unchanged. R1 evidence is not relabelled as r2 evidence.

## Limits of this result

Correlation fields do not authenticate arbitrary supplied memory. The private fixed issuer must retain the same immutable input/reply throughout GROW, and must dispose of BAD sessions. The final Graph owns its copied content and does not reference a reusable arena output.

The component emits complete error text; it does not manufacture Python exception objects, causes or tracebacks. Those public wrapper semantics are a later integration responsibility. Likewise the full batch renderer and foreign in-process capture are not established by this report.
