# Caller-specific native Agent input gates

This is the development ABI for agent_edit_bounded_input.hiaasm. It composes
the frozen Graph wire scan/emit and public integer Agent JSON decode owners.
It does not authenticate arbitrary externally supplied Graphs or peer frames.
The fixed issuer must hold the exact immutable inputs and actual native replies.
Public incremental foreign capture and the ordinary fixed executable remain open.

## Five original caller policies

| Policy | Caller | Earlier byte budget | Result |
| --- | --- | ---: | --- |
| 1 | Single edit response | 16 KiB | Exact response wire and normalized Graph |
| 2 | Batch query / batch display query | 1 MiB | Exact input wire and normalized Graph |
| 3 | Batch response | 64 KiB | Exact response wire and normalized Graph |
| 4 | Single untrusted query canonical comparison | 1 MiB | Canonical wire, without integer re-decoding |
| 5 | Prepared query serialization | 1 MiB | Canonical wire, without re-decoding or error wrapping |

Policies 1–3 preserve the original distinction between exact text/bytes and
other captured Graph kinds. Text's UTF-8 encoding error precedes its byte budget;
bytes' byte budget precedes UTF-8 and grammar checks. Other kinds pass the
complete general native wire owner first. Batch wrapping applies only to this
earlier encoding/wire stage. Later decode errors retain their original complete
E_HIA_EDIT text. Policy 4 retains the original canonical-query exception wrapper.

Single-response isolated-surrogate errors retain UnicodeEncodeError as the
domain and the complete original UTF-8 message, including codepoint position
or adjacent-surrogate range. Both the diagnostic and decimal/hex formatting
are generated by HIA. Domain metadata does not manufacture a Python traceback.

## Entry and BEGIN

RWW buffers are (immutable issued Graph, command-or-peer-reply borrowed read-only,
private workspace). Initial workspace has at least 1,024 zero bytes. Short
buffers return BAD and must be discarded. Normal first growth requests 8,192
bytes. Growth copies every old workspace byte and replays the same immutable
input and command/reply. Completion, refusal or private failure cannot be
reinitialized by a later call.

The initial 64-byte command is eight little-endian u64 words:

    [HIAQWC01, lease, request, rootNode, policy, integerDigitLimit, 0, 0]

Lease/request are nonzero. rootNode is a valid node in the actual captured
Graph. The original Graph header's lease is retained separately for the wire
peer. Root pointers and same-length payloads are not authority on their own.

## Events

Normal return is 128. The sixteen u64 words at workspace offset zero are:

    [HIAQWE01, action, lease, request, phase, neededWorkspace, peer, sourceView,
     sourceOffset, sourceBytes, commandOffset, commandBytes, peerInitialWorkspace,
     errorCode, resultOffset, resultBytes]

- Action 0: completed result.
- Action 1: grow private workspace and repeat the exact command/reply.
- Action 2: invoke the fixed native peer using only the specified views.
- Action 3: completed user refusal, including complete native diagnostic.
- BAD (0xfffffffd): permanently discard the private session.

For peer events, sourceView=0 refers to the immutable first Graph buffer;
sourceView=1 refers to the current private workspace. Command views always
refer to this workspace. A fixed executor copies or borrows the specified
immutable view without looking up JSON fields or mapping error text.

### Peer 1: native general Graph wire

Invoke the frozen scan then emit images with the entire issued Graph and the
actual 64-byte HIAGWC01 command at the event's command view. Mechanically serve
their GROW/NEXT events with shared workspace, initially 32,768 bytes. No hosted
serializer is involved. The command retains Graph lease, request, root,
caller maximum, ensure-ASCII + sort flags 3 and captured integer digit limit.

Return this 64-byte transport header followed by the complete final workspace:

    [HIAQWR01, lease, request, 1, actualReturn, actualWorkspaceBytes, 0, 0] + workspace

The actual return must be 128. The controller verifies the complete terminal
wire event and all bounded views. On success it copies the complete produced
wire to owned storage. On refusal it performs the caller's original error
wrapping in HIA, preserving the wire cause metadata separately.

### Peer 2: native public Agent JSON decode

Invoke the frozen edit_decode controller with the specified raw wire view
and actual 64-byte HIADJC01 command, initially 512 workspace bytes. That
controller requests its own two actual native peers. Its raw kind is 9 because
the caller's earlier text encoding has already produced exact bytes.

Return:

    [HIAQWR01, lease, request, 2, actualReturn, actualWorkspaceBytes, 0, 0] + workspace

The outer controller validates the actual HIAJDE01 terminal event, view ranges
and complete successful Graph header. It copies the complete Graph or diagnostic
into its own storage. Reusing the peer's buffers cannot change published results.
Do not substitute a header plus a separately reconstructed Graph.

## Completed result descriptor

Actions 0 and 3 refer to a 96-byte descriptor at offset 1,024:

    [HIAQWO01, policy, domain, errorCode, causeKind, rawOffset, rawBytes,
     graphOffset, graphBytes, diagnosticOffset, diagnosticBytes, detail]

Success has domain/error/cause zero. The raw view is the exact source bytes or
actual canonical serializer output. Policies 1–3 also retain the complete
normalized Graph. Policies 4–5 have no Graph. Callers compute response hashes
and byte lengths from this exact raw view.

Refusal domain 1 is HIAEditRejected; domain 2 is UnicodeEncodeError.
causeKind records 0 (none), 1 (the wrapped HIAEditRejected), 2 (UnicodeEncodeError),
3 (ValueError category) or 4 (TypeError category). detail retains the wire
peer's underlying cause code for a wrapped wire error. The complete native
diagnostic view is authoritative; consumers must not replace it with a generic
host message. Public traceback/cause-object integration is still separate work.

Phases 1/2 repeat BEGIN; 10/11 repeat wire completions; 20/21 repeat decode
completions. GROW pins the complete transport/event header; successful decoded
Graph GROW also pins the actual Graph header. Immutable fixed-issuer payload
ownership remains necessary beyond these correlation checks.

The current independent VM/actual-B3 source has 25 functions, 352 blocks,
67 maximum blocks per function, 2,253 operations and 9 maximum block parameters.
No original compiler source/output/workspace, CPU, wall, address-space or cold
limits have been raised. Final native differential/protocol evidence is recorded
separately; this ABI document alone is not qualification.

## Original development observations

Authoring r1 rejected an attempted bool-to-u64 cast; its original source and
exception remain retained. Source r2 used an explicit choose operation and
compiled under the original gates. Its native run passed 196 public cases and
62 private controls, after which a separate actual-image counterexample showed
that a successful wire completion awaiting growth could be replaced by a valid
error completion. The old controller returned semantic refusal instead of BAD.
That private protocol failure remains a failure, including all original buffers.

Source r3 moves the pending-frame binding check before every terminal branch.
Its source is 119,124 bytes, SHA-256
fcea83f4c992e6d668e29049cf17386c60b8bfe79b467d7ec48874c77efb6f1d;
the actual image SHA-256 is
5e103e2db22226607437a4bbd5ac648d12b8dab3ab9f369fc78196ac43a0df32.
Nine independent VM cases made 35 entries before actual B3 compilation.
The unchanged 196 public cases plus 63 private controls then passed in
8.997890849 seconds. There were 985 outer-controller entries, 149 wire scan,
186 wire emit, 527 decode controller, 88 raw decoder and 176 arena-Graph entries.
Every native call retains whole inputs, replies and before/after workspaces by
content hash, with immutable inputs and canaries checked. Four whole-workspace
VM pairs were performed outside the hosted-owner prohibition region.

These observations cover the five caller policies, exact error domain and
message, normalized Graph and raw bytes, the three integer digit profiles
0/640/4300, byte and multibyte boundaries, aliases/cycles, unsupported kinds,
finite float serialization followed by integer decode, and pending reply binding.
They do not close public foreign capture, Python exception objects, the ordinary
fixed coordinator, cold performance, or the full retained regression.
