# Inspect private source and machine stages

## Present executable proposal

The present `SOURCE-PLAN.json` enables exactly two consecutive, separately
owned groups: the original Source10 and the independently declared Source8
physical-entry controls. It has no actual product result until Root explicitly
authorizes its unique launch. This proposal does not rerun generation, the
retained original three tests, or the retained CLI43 group. It invokes no HIA
compiler, native image, Core VM group, cold qualification, or CLI op10 route.

The same runner contains the later build, seven original Native groups and two
original VM groups. They are inaccessible through this plan. `active_phase`
must equal the explicit parent invocation, and the later `native-vm` phase
requires a separate reviewed `NATIVE-PLAN.json` with the full descriptor of
this stage's actual successful result. No such plan or future result pin is
supplied in this package. This is a shared implementation, not authorization
to proceed automatically from Source18 to any later owner.
