# Native component cold readback

Bootstrap construction/caller readback and the seven-image Budget reader now
admit the native cold source domain without requesting invented legacy Python
isolation fields. The data-only reader reconstructs the current native contract
from the complete physical authority and metadata, applies the original 14
checks, 60 phases, 19 families, three generations and unchanged 180+3 limits,
then reads every original generation location. Existing legacy cold checks
remain in their own branch. Host component inputs independently revalidate
their exact clean Git commit/tree/blob custody and terminal physical bytes.

The native compiler images are raw flat x86-64 code. The previous location
reader incorrectly required an ELF header. The original refusal with the
actual 641,344-byte compiler is retained, along with its passing location-only
control after removing that unsupported format assumption. Exact byte count,
SHA256, three distinct physical paths and the mandatory full cold gate remain.
That location control used three temporary copies and makes no claim that it
performed cold self-hosting; the JSON records this explicitly.

The final no-skip regression passed 26 tests: eight adversarial independent
readback groups, six original native admission groups, four original Bootstrap
caller readback groups and eight original generation-location groups. These
tests deliberately use synthetic control reports, which are not qualification
evidence. The initial missing-fixture failure is retained; the already tracked
fixture was restored before the full original module passed. All original
failed and successful gate logs are preserved without editing their bytes.

An additional actual development construction built all six original companion
images and read back their complete native compile outputs and 214 physical
captures in a fresh isolated interpreter. Imports of product modules,
generators, builders and oracles were forbidden during readback. This passed
in 1.510204045 seconds. The complete 62-file attempt is retained in the
406,279-byte archive and every member was independently hashed after packing.

These component/readback results do not replace a real matching-source cold
run, the full original caller suites, installation or whole native delivery.
The original native report and images are consumed separately when available.
