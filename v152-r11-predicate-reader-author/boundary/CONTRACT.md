# R11 actual predicate and lexer/identifier boundaries

This is one additional private VM control owner. It does not run a compiler,
Native image, the checker entry `f0`, or any of the original eight groups.
It has no authority to replace any previous failure or authorize those groups.
Root alone may launch the frozen command after review.

## Actual input boundary

The exact R10 and R11 generated HIA sources are reparsed by the unchanged
assembler and verifier in the frozen 3,180-file source tree. The resulting
107-function, 1,456-block documents must match the real generation proof and
invert completely through exactly the two predicate operation lists. R10's
6,299 and R11's 6,270 operations are checked separately. The actual R11 prefix
independent reader is a necessary predecessor, including its three complete
proofs, nine scalar edit paths and two predicate edit paths. Its tool-display
RETURN was truncated; the original RETURN is retained as truncated, and the
complete on-disk RESULT is independently pinned. No missing stdout is rebuilt.

## Real control calls

Pure scalar fragments are extracted from the actual verified operation lists,
with exact live-in SSA names and the original Boolean result. Both fragments
are independently verified as new one-function Core documents before actual
VM invocation. The small independent set/range oracle checks only the two
scalar predicates, never the lexer or the checker policy. All 256 byte values
and the frozen unsigned 64-bit boundary values are used; the identifier index
classes are zero, one and the maximum unsigned 64-bit value.

Full-function controls invoke the actual complete R10 and R11 `f16` and `f79`
bodies. They include all 256 first bytes and identifier-tail bytes, delimiter
neighbors, quoted and unquoted text, numeric and identifier length boundaries,
reserved spellings, high and past-end cursor fields, preexisting first errors,
every relevant partial metadata write, short source, invalid views, read-only
workspace, dirty untouched bytes, and explicit shared-owner inputs. They do
not narrow the production domain to these fixtures. The static full-width
proof and the original complete eight-group matrix remain separately required.

Each full-function invocation has its real two-buffer ABI. Actual source and
workspace bytes are captured and read back before entry and after every
observed return, trap or rejection. Shared-owner cases have one physical
bytearray and two explicit logical observations. Scalar fragments have zero
buffers; no fictitious source/output/workspace frames are created. Missing
observations fail the gate and are never filled from the oracle.

## Observation and comparison

The observer directly subclasses the unchanged `_Machine`. It inherits the
original `invoke`, `tick`, resource accounting and implementation. Each
operation delegates exactly once to the original operation body. It records
already-evaluated scalar or view operands, complete ordered buffer and call
events, real returned values or exceptions, real predicate results, resources,
and view/owner state. It never calls `_underlying` or performs a buffer access
to prevalidate an operation. Observation does not change or bypass fuel.

R10 and R11 must have equal outcomes, exact error type/code/message, ordered
buffer/call effects, all initial/final bytes, owner state, resources and
predicate results. Operation streams and step counts are recorded but are
not required to be equal because the two pure operation lists differ.
All bytes outside successful actual write extents must retain their original
dirty values. Unexpected errors and budget exhaustion are failures even if
both versions exhibit them. No callback or owner mock supplies a positive.

## Original limits and failure behavior

Each actual VM uses 10,000,000 steps, 1 MiB heap and depth 128, with no injected
allocation failure. One original owner has 180 seconds plus three seconds
cleanup; the unchanged outer watchdog is 1,800 plus three seconds. The fixed
3 GiB entry storage floor, explicit runtime environment, supervisor environment,
real request/receipt/streams/exit/cleanup and complete before/after guards are
retained. All 6,777 original fresh-domain files and 948,620,735 bytes are reread;
no digest, result, source or fixture cache replaces a fresh read.

The first incomplete observation or unequal case stops the remaining cases.
There is no retry. All errors, partial frames, begun and unstarted case IDs,
owner results and final guards are retained. Original R4/R9/R10 failures and
unstarted suffixes remain unchanged. A PASS here establishes only this added
finite boundary gate. It establishes neither cross-target 10M completion,
matching current cold, whole Native qualification, nor default selection.
