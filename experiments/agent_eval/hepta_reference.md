# Hepta subset reference

Functions require effects clauses. Locals: let x: u64 = 0; or let mut x: usize = 0;. Assignment uses =. if/else, while, for i in 0..n, and return all use braces; statements require semicolons. Casts use x as u64. Integers infer from the expected type; uncontextualized integers default to i64. Operators are Rust-like. Integer arithmetic and indexing check overflow/bounds even in optimized builds; wrapping_add(a,b), wrapping_sub(a,b), wrapping_mul(a,b) have explicit wrapping semantics. Raw memory operations must occur inside unsafe { ... }: load(pointer,index) reads a pointee, store(pointer,index,value) writes it. Struct values use Name { field: value, ... }. There are no methods, string values, macros, indirect calls, or external packages in this subset. Functions declare transitive effects; the frozen interface already provides the required upper bound. The native backend is pinned rustc.
