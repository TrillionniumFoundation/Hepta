integer/string inputs agree, but the sequence of comparisons is not CPython
TimSort/Powersort's sequence. Exact foreign keys may mutate values between
validation and later observations, and opaque or inconsistent comparisons may
observe this difference. The complete foreign comparison schedule is therefore
an explicit unresolved API boundary.
