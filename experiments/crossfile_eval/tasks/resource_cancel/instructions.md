Repair cooperative cancellation across service and worker. For length n >= 2, service allocates exactly one n-byte input buffer, writes mode (0 normal / 1 cancel) into byte 0, and initializes remaining bytes to i % 251. It transfers that buffer to one real worker thread. The worker must checksum bytes 1..n and release the buffer before returning. In mode 1 it waits until the shared cancellation flag is true, then adds 1000000 to its checksum. service must signal cancellation and join in mode 1, or join normally in mode 0; no detach. Lengths below 2 return -1 without allocating or spawning. Inputs are 0..4099 and mode 0 or 1. The native evaluator checks matching buffer allocation/deallocation and actual pthread creation/join counts. Cancellation is cooperative, and a timeout is failure; this task does not claim a scheduler-independent latency bound. Keep frozen main unchanged.
