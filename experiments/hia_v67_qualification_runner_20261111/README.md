# v8 qualification controller: unchanged original gates, additional owners

This directory contains hosted validation machinery. It is not a native
production owner and does not establish whole HIA-native delivery. The exact
original v7 runner is retained beside the v8 runner. The original external
guardian and process owner are unchanged, including the 10,800-second complete
run budget, 180-second cold limit, two cold workers and all 38 phases.

The v8 runner preserves the original source-identity and local-clone
reproduction functions, all existing native groups, and the complete retained
regression. The ordinary journal, machine-plan and wire denominators remain
94, 44 and 89. Loaded IDs must match executed IDs, and failures, errors, skips,
expected failures and unexpected successes must all be zero.

New admission requires the complete wire-cache module, the 17-method CLI
module and the instruction-byte qualifier's 9 component plus 51 unchanged
caller tests. Each gets its own retained fixture directory. Development
selectors are cleared; each new build must bind the actual current-source
cold report, declared sources and original compiler generations. All 37
instruction commands must execute without entering a retained encoder.

The CLI gate requires the actual 15 action observations and 23 original file
branches, the six original ordinary caller modules, and both cold-built HIA
images. It additionally validates an actual wheel, installed Python custody
bytes, both declared HIA resources, isolated `-I -S -B` execution with empty
PATH, eight ordinary calls, nine selected-resource/bundle refusals, and
original subprocess stdout/stderr. Old parser/CLI and authoring entries must
remain empty. The tests still call hosted action business bodies; this is
native CLI control and presentation, not a standalone native product.
