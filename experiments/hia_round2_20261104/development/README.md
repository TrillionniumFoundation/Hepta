# Round 2 completed development evidence (2026-11-05)

This package preserves the selected completed source-development evidence, including failures. It does not rerun, reclassify or combine experimental cohorts. Source commits and scopes remain in the original receipts.

Download all files in this directory, then run `python3 RESTORE.py --target <new-empty-directory>`. The restorer checks each part, the complete archive, every member and every restored file.

Human work, energy and any unobserved historical costs are unknown, never inferred to be zero. Delivery compression and verification costs are separate from study costs.
