此记录只证明一次新的私有运行依赖构建成功，不是 HIA 原生资格、CLI 17 项、46 组跟踪或整套改写通过。

最终解释器位于运行主机的任务私有目录，29,756,920 字节，SHA256 `1dbbe782bad1bf4519a583edbefcb9544971f39b0ea93fb874d0515283e76401`。隔离探测已导入 ctypes、mmap、ssl、zlib、bz2、lzma、resource、sqlite3 和 sysconfig。下一实际 HIA 运行仍须独立准入这个新解释器的符号、文件与内存映射；任何旧运行记录都不能替代该步骤。

原始来源为 [Python 3.12.14 官方发布](https://www.python.org/downloads/release/python-31214/)，XZ 原件 20,820,300 字节，SHA256 `5c8462af5790baf43a321a1559dbe0db06d1be4300fb85fb53c40060668e548a`。4,577 个原始普通源码文件的完整清单、提取结果及四份 CPython 语义参考原文均保留。构建使用私有 prefix，不改系统解释器；缺少的开发包仅下载并解包到任务目录。

## 原有失败保留

第一次外层启动把 900 秒交给仅接受原上限的进程控制器，因此在实际构建 worker 启动前被拒绝。该启动脚本与 intent 原样保留。随后依赖构建的 configure、make、altinstall 虽各自成功，隔离探测因缺少 _ctypes 失败，整体仍为 HOLD。补齐私有开发头文件后，在新的目录构建成功，实际 durable job 为 `1a1d3654e33-392-11b`，耗时约 42.56 秒。

这些是运行依赖供应步骤。HIA 资格的 180 秒与 3 秒清理门限没有因此改变。
