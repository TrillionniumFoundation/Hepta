## Concrete change

The original cold branches built genuine matching-source state/instruction/encoding images for callers, but ran the component class by clearing its cold selector and transporting that bundle through its explicit development selector. The candidate instead passes the same actual cold report to the complete component module and clears the development selector. Its original setUpClass now performs its own strict cold builds.

The existing class-level wrappers and all existing counters remain. Their counters increment before the original method and are explicitly described as **selected-call attempts**. A foreign/domain exception leaves the old attempt ledger intact. New counters increment only after the original selected method returns normally. They are indexed by group, owner kind, actual mapped image SHA256 and operation; an image-identity change across a normal return is retained and refuses qualification.

Component setUpClass is wrapped solely to capture its actual source/compiler/manifest/image/build binding after setup and before the first native method. The original bound setUpClass is called exactly once, without replacing test bodies or IDs. Caller bindings are captured separately before their original group starts. Every captured manifest, image and cold build file is retained and compared again by complete bytes. Cold outer/nested/B3 identity and the complete current source map are independently admitted and reread. Failed or incomplete groups retain their before-bindings and partial ledgers.

Final coverage only combines normally returned operations from the separately admitted component/caller images. Both groups must have native returns; each group need not independently cover every opcode. The union retains the original complete 6 state/37 byte or 41 instruction/6 state/37 byte sets. All existing attempted-operation set checks remain as additional checks. A caller group cannot borrow a component group's successful-call count.
