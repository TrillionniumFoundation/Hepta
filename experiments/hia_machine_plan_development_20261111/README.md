## Preserved failed and superseded observations

The archive retains the earlier r1/r2 development observations and their actual
HIA inputs/images. The original r1 Python authoring generator was not copied
before it changed; this record does not claim complete custody of that generator.

An independent review found five real foreign-callback mismatches in nine r2
cases. The full probe, stdout, stderr and receipt remain unchanged. The corrected
r3 HIA protocol now requests the original ordered dictionary operations and
truth conversions; it passed all nine cases. Earlier random passes did not
establish the missing callback semantics.

The initial integrated native test execution had eight passes and one test
fixture error: its helper was called with an unsupported keyword. Its original
log, result and input snapshot remain included. The subsequent fixture repair
and corrected executions are separate records.

The first expanded r3 differential execution passed its checks but its probe
recorded a stale r2 source digest from the draft directory. The original record
is preserved with `IDENTITY_CAVEAT.json`. It is not qualification evidence.
After correcting the probe's source path, the complete differential was rerun;
`corrected-differential-observation.json` is an exact copy of that new result.
