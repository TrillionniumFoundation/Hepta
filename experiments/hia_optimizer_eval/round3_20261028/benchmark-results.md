# 第三轮：受证窄化的八臂原生对照

**在本次登记的两个内核、输入分布和共享 x86-64 主机上，112 个样本全部保留，质量门槛通过，14 项联合非劣门槛通过；其中对五个 Rust/C/C++ 强基线的 10 项比较也全部通过。** 这是一项有限范围内的新正结果，前两轮的负结果保持原样。

## 观察与身份

- 8 个臂 × 2 个内核 × 7 组，共 112 个实际样本；无删样、无重试、无改门槛。
- 1,344 个原生正确性用例全部通过；每次检查实际 sealed image 和函数映射。
- 3,472 个批次、28,784 个单次调用延迟和 7,280 个时钟开销观察全部保留。
- C/C++ 分别在新训练集上进行两次真实 PGO 训练，并合并 profile、LTO 重建；没有使用旧 profile 或 holdout 训练。
- 130 项源文件绑定、显式工具、Python、SMT 和环境登记在执行前冻结；最终源码、工具、环境、解释器和产物身份全部未变。
- 使用 CPU 0（许可集合 0–8），运行期间固定该 affinity；这是共享主机，不是独占物理机。

HIA 的生产准备区间覆盖实际确定性提案与 fresh proof / LLVM emission / compile / identity check / atomic publication；不复用外部 receipt。候选提案耗时 0.083533895 秒，随后证明、编译和发布耗时 4.173845277 秒。共享 HIA frontend 另外测得 0.009624084 秒；候选与原版都需要它，二者差分回本计算中相消。C/C++ PGO 的准备区间包含 instrumentation、真实训练、profile 合并及使用 profile 的重建。

原 HIA 准备为 0.223848067 秒，候选为 4.257383744 秒，额外成本为 **4.033535677 秒**。按本次平均调用节省，full_lifecycle 的点估计回本量为 **1,173,569 次调用**，packet_xor 为 **649,912 次调用**；节省率来自该固定输入混合，不能作为未来负载的保证。

测得 `run()` 实验区间为 **21.866697600 秒**。内部子进程区间总计 11.760508875 秒，已经嵌套在实验区间内，不能再相加。进程启动、执行前 registration 核验、最终报告序列化不在该 `run()` 区间，归档单独记录；工具下载、人工工程时间仍为 unknown。这里没有宣称所有经济成本已知或完全无缓存冷启动。
