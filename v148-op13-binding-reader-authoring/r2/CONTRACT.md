# Independent op13 completed-binding readback, draft R2

This new standard-library reader is for Root to review and run against the actual
BOUND_NOT_EXECUTED binder. Authoring did not execute the reader, binder or product.
The reader is a separate implementation; no prior verifier PASS is inherited.

## Exact input and full-read scope

The frozen 24,783-byte PREPARATION-PLAN is hard-bound by full bytes, SHA256, Git
blob and Git mode. LAUNCH supplies the actual BOUND-PLAN and BINDING-RESULT SHA256.
All carry fields and exact added fields must agree with the frozen plan. The
source map must equal the projected bytes and recompute the expected 3,210-file
Git tree. COPY-ROWS and COPIES must agree in original sorted path order.

Each of 3,210 original authorities and 3,210 actual copies is freshly opened and
read completely; full pins and bytes are compared. Modes, held/named seven-stat
values, unique old/new inodes and disjointness are checked. The 3,180 protected R8
sources and all 2,496 runtime files get separate complete reads even when a prior
pass read identical bytes. No digest cache avoids reads; the identity dictionary
only records final stat checks. Complete file/directory pathsets and final stats
are checked again. Only six binding metadata files plus the exact source subtree
are permitted in the scope. The source root must remain 0700; every directory mode and seven stat fields
must match actual frozen SOURCE-STATE and terminal inventory.

The binder's actual runtime record is compared to the current exact executable
and library and to Root's prior actual stdlib readiness report. The three
sysconfig values are obtained by ast.literal_eval of the exact restored
_sysconfigdata_ source, without import or execution. This is not a new live
process-mapping probe, old-venv restoration or availability proof for missing
site-packages. No restored binary is launched by this reader.

## Boundaries and failure handling

Only a new absent output directory outside protected roots is written. The
original actual /dev/shm 1 GiB floor and product-attempt absence are checked at
both ends. No source, fixed authority, runtime or existing binder evidence is
written. Normal failures retain traceback and partial full-read ledger in the
new output and return nonzero, with no retry or fallback. A killed reader can
leave incomplete output and is not a successful readback.

SOURCE-BYTE-READBACK retains all 3,210 descriptor pairs. COMPLETE-STATE-READBACK
retains complete scope/source/protected-R8/runtime path and stat maps.
FULL-READ-LEDGER retains each fresh read; RESULT records the limited conclusion.
Estimated additional metadata is at most 24 MiB, with no source-payload copy.
At least 12,096 complete payload reads are prescribed, plus fixed metadata and
repeated explicit runtime inputs. Actual counts are measured only by Root's run.

The original 180+3, 20-second compile, 1 MiB image, 10M VM steps, 8 MiB heap and
128 call-depth limits are unchanged. No product or HIA/VM operation is run;
all_frames_retired, whole, default and current-cold qualification are not granted.
The separate actual outer recording remains original evidence; this reader does
not turn outer exit0 into product success or invent any owner/cleanup observation.
