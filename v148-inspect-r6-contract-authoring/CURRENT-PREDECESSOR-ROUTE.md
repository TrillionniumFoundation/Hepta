   Original deliberate lost-return/unknown-ownership evidence is retained;
   no invented cleanup or after-frame is substituted.
5. Retain every actual new source map, request, owner, stdout/stderr, entry

6. Only then author a distinct versioned current-R6 binding whose exact

   complete new R6 eighteen-group sequence, including all currently unclosed

The plan keeps every future result, custody recipe, actual view and launch
field null. There is no current executable launcher in this package. The
authoring exercise identified a local reader-schema mistake: the original
kit's `after` object also contains full `text`, so a four-field pin cannot
equal that five-field object. The first static author attempt and traceback
are preserved. The independent R2 reader checks the exact five-key shape,
the duplicate text equality and all four pins, and reuses only already-written
author files with exact bytes/mode. No product or source was changed to make
that author check pass.
