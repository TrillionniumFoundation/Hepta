## Original assertions that block silent integration

`PatchCliSourceTests.test_complete_union_binds_every_added_file_without_worker_expansion`
requires exactly 3,191 R5 rows, 14 Patch rows and a real recursively scanned
3,210-file product view. It also requires every row in the selected R5 and
Patch maps to equal the complete projected map. The old R5 map cannot satisfy
this assertion after these three files change, even when the count is 3,210.
The 3,211-file mother separately fails the original count. Both constraints
remain intact; this candidate changes no test body or assertion.

`PatchCliSourceTests.test_original_patch_policy_and_selected_prepare_are_not_rewritten`
checks all selected Patch14 rows, including the generated Patch data file.
The later actual generation therefore requires an explicitly versioned
Patch14 map. Its original policy functions and all 14 paths remain required.

The original Inspect test
`InspectProgramSourceTests.test_generated_policy_ports_and_host_compatibility_are_reproducible`
and Patch test
`PatchResultSourceTests.test_generator_emits_complete_reproducible_core_and_actual_host_pins`
will reject stale generated data. Their assertions are useful gates, not
conditions to remove. The Patch fixture's other 23 retained-file hashes do
not include the three proposed files or these two data files; no exemption
for unrelated retained files is proposed.

The retained 140-observation driver's `require_native=False` means native
entry is not required for that old case, not that native entry is forbidden.
Its normalize case therefore does not statically conflict with an additional
op8 native entry. The full original 140 observations and all 43 CLI IDs still
have to run, with their unchanged comparison and lifetime assertions.

## First execution boundary after review

The narrow first gate can use a newly built six-image report bundle with this
three-path overlay, the original 12 Source methods, original report two-method
group/all 140 cases, original CLI43 and the eight external op8 controls.
This does not require pretending the old Inspect/Patch hosts match. Any later
combined-stack run first needs the actual generation, versioned full maps,
new compatible component manifests and its own original complete gates.

No default route is activated by this candidate. The removed foreign policy
owner is the direct `VerifiedProgram.as_dict` body in an explicitly selected
claimed op8. JSON decoding, the verifier, object ports, output/publication,
Worker/Service construction and SQLite remain real foreign providers.
