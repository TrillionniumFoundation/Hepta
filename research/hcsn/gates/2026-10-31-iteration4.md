## Eliminated artificial blocker

The legacy status manifest permanently hardcoded `full_closure=False`, even if legitimate independent evidence arrived. `gate_evidence.py` now queries `independent_gate.py` for **dynamically verifiable evidence**. Missing or malicious evidence fails closed, but fully independently attested evidence can move each gate to `INDEPENDENTLY_ATTESTED` **without** enabling production.

`independent_gate.py` requires: immutable 40-hex source commit, separate trusted release root outside the evidence/source tree, external Evaluator+Observer distinct Ed25519 public keys and signatures, preregistration SHA256, per-gate required topics, bounded signed relative artifact paths, and SHA256 of each artifact. No signing private keys are stored in the repo. It does not claim that signed evidence alone constitutes independent scientific validation: external reviewers must inspect protocol, numeric methodology and benchmark fairness.

4 new integrity tests verify missing trust-root rejection, unauthorized/self-authored trust-root rejection, file tamper/key substitution rejection, and a **synthetic technical-signature fixture** which can satisfy the abstract protocol while leaving `production_activation=false`. The test fixture is synthetic, **not scientific evidence that any phase is closed**.

## Remaining scientific / production blockers

- **P0** global admissibility, original HX degeneracy as direct A7 formula vs numerical Green fallback, rigorous QVI all-domain/time-varying bounds, low precision and target hardware.
- **P1** independent preregistered benefit against matched strong controls at matched FLOPs and slopes; current conventional gates have stronger results on existing toy decision tasks.
- **P2** many-seed long-horizon retrieval, autonomous multireset stability and exact event/BPTT equivalence; existing HCSN underperforms GRU on long-memory heldout.
- **P3–P4** real multimodal pretrained encoder weights/datasets, frozen matched-parameter/compute baselines, entity/time alignment, independent missing-modality eval.
- **P5** actual target GPU fused kernels, end-to-end device energy/power, full-model throughput/RSS/p99.
- **P6** medium encoder model training, distillation, continuous pretraining and reproducible quality-cost frontier.

All seven phases remain OPEN, not a defaulted failure due to hardcoded gates; results are scientific evidence-limited. Research branch only, draft PR #468, not merged.
