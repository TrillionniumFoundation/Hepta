# ChatGPT Library source recovery: Hepta independent P0-P7 audit and native C++ fixtures

This is an isolated, historical source-only snapshot, not a production activation or a current toolchain qualification. Some files may be test fragments or patches; scripts are not guaranteed to execute standalone without their exact source-tree, fixture and toolchain dependencies.

Run `python3 verify_snapshot.py` to verify exact source SHA-256 and Git Blob SHA-1 identities. Python syntax can be checked with `python3 -m compileall -q files`; executable shell scripts can be parsed with `bash -n` where Bash is available. This does **not** establish production soundness, ABI validity or acceptance thresholds.

The generated manifest pins each original Library file. Raw evidence archives, checkpoints, models and large logs are intentionally excluded. No current production source path is overwritten. Any historically pinned program should be applied only after a separate semantic and source-lineage review.
