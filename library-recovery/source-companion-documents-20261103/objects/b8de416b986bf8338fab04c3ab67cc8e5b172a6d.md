# Hepta CSN P0: simplified optimal-stopping reference

This is an **independent, deliberately limited prototype**, NOT a reproduction of He & Xiong's full rollover-risk/debt-pricing equilibrium. It does not establish the HX closed-form kernel, regenerative QVI solution, training superiority, GPU performance, or production readiness.

## State dynamics

`dS = mu*S*dt + sigma*S*dW`, `S>0`, discount `rho>max(mu,0)`, strike `K>0`. Continuous perpetual optimal stopping for call reward `(S-K)+` and put reward `(K-S)+`.

Generator `L f = mu*S*f' + sigma^2*S^2*f''/2`, obstacle `max((L-rho)V, g-V)=0`. Characteristic roots solve `sigma^2 beta(beta-1)/2 + mu*beta-rho=0`; use the positive root (>1) for call and negative (<0) for put. Analytical threshold and value are independently compared against a projected finite-difference obstacle solver in log space, which does **not** use the analytical threshold in its solver.

## Scope and known gaps

- Four validation instances (two parameter sets × call/put) pass. This is **not** coverage of the full valid domain.
- Current call/put formulas model a simple reward; labeling their output as a biological neuron is unwarranted.
- Finite difference has finite-domain truncation, including a non-negligible put error at the second parameter point. Mesh and boundary convergence require a dedicated sweep.
- `qvi_one_state` is a single Bellman projection sanity check, not a coupled regeneration QVI solution.
- Next gates: reproduce published HX equations and verify source/parameter assumptions; independent QVI solver with intervention costs; gradient comparison across boundaries, float32/bfloat16 testing, limiting regimes, and full metamorphic tests.

## Stage-2: coupled regenerative QVI numerical reference

Run `python regenerative_qvi_reference.py`. This implements a finite-state,
**two-regime coupled impulse/switching Bellman QVI** with instantaneous
strictly-positive-cost regeneration. The Markov approximation uses a reflecting
one-dimensional state interval and explicitly checks its CFL/stochasticity
condition. It compares **independent policy iteration (linear-system policy
evaluation)** against **Jacobi Bellman iteration** for 5 intervention costs,
checks Bellman residuals, regime-specific intervention, monotonicity in reset
cost, and invalid parameter rejection. Both algorithms agree to <2e-8 in the
included cases. The high-cost limiting case has no regeneration regions.

This is a DISCRETE numerical QVI reference, **not** an analytic closed-form
regenerative QVI and **not** He-Xiong model reproduction. Further necessary work:
source-exact paper mapping, continuum grid/time convergence with an independent
continuous-time solver, parameter sweeps, gradient/precision tests and neural
training ablations. No GPU, Rust kernel or multi-modal benchmark is claimed.
