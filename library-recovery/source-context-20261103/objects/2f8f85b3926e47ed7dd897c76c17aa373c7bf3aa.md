## Run on Linux with Python 3.11+, Clang, GCC, Clang++ and G++

```sh
PYTHONPATH=. python3 -m unittest discover -s tests -v
PYTHONPATH=. python3 scripts/qualify.py
PYTHONPATH=. python3 -m hia_candidate migrate-c fixtures/c/add_zero.c
PYTHONPATH=. python3 -m hia_candidate run examples/buffer_roundtrip.hia.json --inputs '[4]'
```

The qualification command stores source digests, native binary digests, actual tool versions, test logs, negative outcomes, synthetic planner controls and a strict P0–P7 gate ledger in `reports/`.

## Implemented *bounded* research profiles

- **P0:** one versioned JSON opcode contract; strict canonical input; immutable source identity, re-admission at every execution, explicit effects, single-block SSA and scalar returns.
- **P1:** u8/u32/u64, checked overflow, wrap, first trap, VM quota, `buffer.new`/`try_new`, owner move/drop, shared/exclusive loans, explicit loan end, allocator-failure schedule, stopped resource ledger.
- **P2:** native C ABI scalar code generation, real GCC/Clang compilations and C layout/offset differential on the current host; a real AArch64 relocatable ELF object is cross-compiled but **not executed**.
- **P3:** Clang AST strict single-function `unsigned int(unsigned int)` migrator supporting unsigned `+`, `-`, `^` and literals, with whole-input refusal of globals, pointers, macros, calls and unsupported statements. Clang reads a frozen, bounded stdin snapshot rather than re-opening an attacker-controlled path.
- **P4:** two synthetic versions of a C++ RAII opaque-handle C ABI library compiled independently by g++/clang++; native stale-handle/overflow/double-destroy and zero-live-owner checks. This is **not** a real third-party upstream migration.
- **P5:** explicitly algebraic `x + 0 -> x` modulo-width rewrite, immutable candidate digest, native scalar differential. **No generic SMT/e-graph, strong Rust speed comparison, or net positive gain claim.**
- **P6:** same-information finite exhaustive search, DP and Q32-styled advisory proxy. **Not the original native Rust NDU.** No additional NDU advantage claimed.
- **P7:** local interpreter source-store, durable generation-CAS pointer, source re-verification, after-store crash injection, restart and rollback. **Not native live-process patching, cross-node recovery, signed authorization or production deployment.**

## Safety boundaries

The verifier and interpreter in this pilot are Python reference implementations, and have not been proven formally correct. No broad C/C++ translation, floating-point, pointers, threads, foreign calls, full ABI, device I/O or arbitrary recursion is admitted. Metadata checksums are not signatures; the local host and file system remain trusted. `max_heap_bytes` is logical payload, not RSS. `max_ticks` is interpreter events, not CPU time or WCET. Physical hardware and Agent productivity remain unqualified.
