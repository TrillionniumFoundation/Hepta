## Method and assumptions

For signed log-margin `X_t>0`, use `dX_t = mu dt + sigma dW_t` until first passage to 0. After an event there is a fixed refractory delay `rho` and a new margin `R_z` from modes `z in {0,1}`. First post-event mode `Z_1 ~ pi`; later `Z_{j+1}|Z_j ~ P[Z_j,:]`. Mode chain is independent of the Brownian path, and transitions only after events. Under these restrictions, the nth event time law is:

`Pr[N(T)>=k+1] = E_{Z_1...Z_k}[ F(T - k*rho, x0 + sum_{j=1}^k R_{Z_j}) ]`.

The discounted kth-event transform is analogously `exp(-lambda*k*rho) * E_Z[G(T-k*rho, x0+sum R)]`. `F/G` are the exact affine Brownian first-hit CDF and truncated discounted transform. A two-state count DP evaluates this in `O(K^2)` (not `2^K`) and returns exact count probabilities `N=0...K`, separate right-censored `P[N>K]`, bounded expected count and discounted event reward.

**Scope:** this is an exact finite-horizon scalar Markov renewal *submodel*, not the original He–Xiong equity valuation/free boundary/QVI, not an input-adaptive boundary, and not learned long-context memory.
