# Hepta Intelligent Assembly — independent P0–P7 qualification probe

**Research-only, `DENY_ALL`, not integrated into Hepta.**

This additive kit is an independently written **bounded-profile experiment**, not a copy of `hepta.hia_program` and not a proposal to replace it. It tests whether a strict `u32` SSA/Clang/owner prototype can reject unsafe inputs, reproduce real native results, and account honestly for optimization costs.

## Verified local scope

- `hia_probe.py`: explicit schema, closed single-block SSA, `u32` wrap arithmetic, checked arithmetic/traps, bounded Clang AST conversion for one C function, real GCC/Clang C output and fail-closed straight-line owned-byte resource analysis.
- `test_probe.py`: adversarial parsing, schema, type, SSI/SSA, ownership, C translation and independent original-C / generated-C / interpreter differential checks.
- `test_traps.py`: traps are observable. Checked arithmetic uses a separate status-return ABI and compares against actual GCC/Clang output, including negative cases.
- `cpp_bridge_fixture.cpp`, `cpp_c_consumer.c`, `test_cpp_bridge.py`: real, **toy** C-to-C++ ABI, RAII/exception/handle-generation controls compiled and run under Clang and GCC families. This is **not** a third-party library migration.
- `economic_probe.py`, `test_economic_probe.py`: full declared one-time cost accounting and same-information fixed/greedy/exact-DP/exhaustive controls, with a native NDU **UNAVAILABLE** marker. Numbers in the fixture are synthetic, **not** an observed application speedup.
- `qualify.py`: executes all tests and writes a source-bound machine-readable receipt to `evidence/`; complete negative outcomes remain visible.

No Rust, Lean, GPU, ARM64, real third-party maintenance cycle or existing Hepta checks are run in this kit.

## Run on a Linux host

Requirements: Python 3.10+, Clang + Clang++, GCC + G++ (for full native differential qualification).

```bash
python3 -m unittest discover -p 'test_*.py' -v
python3 qualify.py
```

All tests are written with `unittest`; no Python package download is needed. The native tests compile and actually execute shared libraries and C/C++ consumers. Any missing native tool causes a reported skip, and `qualify.py` marks skip-containing runs as unqualified.

## Security/trust limits

1. The schema `hepta.audit.scalar-u32.v1` is a **separate research schema**. It is **not** a released Hepta Core profile. The `const`, wrap/checked arithmetic semantics are limited to 32-bit unsigned scalars, one SSA block, no calls/branches/loops, and checked traps only in this prototype.
2. The resource checker is straight-line with explicit allocate/move/borrow/end/drop operations. It has no whole-language lifetime theorem, nonlocal exits, allocator failure semantics, async cancellation, concurrency, foreign pointers, DMA, memory-mapped I/O, stack/RSS bounds or crash recovery. `peak_payload_bytes` excludes allocator metadata and process RSS.
3. Migration accepts one `unsigned int` return-expression function and only explicitly allowed operators. It rejects whole translation units containing unsupported top-level declarations. Clang AST must be bounded. It is **not** a general C99/C11 translator.
4. `unsigned int` width is checked to be 32 bits by native `_Static_assert`. The local C ABI tests prove only the observed toolchain/platform slice. Native and source semantics are not universally proved.
5. The C++ fixture has a mutex-protected generation handle and exception-to-error conversion; its correctness on a toy case does not establish a generic C++ ABI or fully safe foreign library ecosystem.
6. The cost planner trusts its supplied dataset and evidence digests; it **never authorizes execution**. Synthetic positive numbers are not real performance evidence. Unknown one-time cost components are refused, and NDU is not replaced by a mock that claims victory.
7. Regressions, bounded cross-compilation observations, and tests are not full-machine refinement or proof of superiority to optimized Rust.
