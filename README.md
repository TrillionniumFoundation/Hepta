partial execution, source drift or held input drift make the run fail. Each
group has a unique output area. No business operation or failed group is retried.
The artifact is uploaded on failure as well as success and retains complete raw
logs, terminal reports, wheel/build/install files, actual selected image/receipt,
full source export and harness inputs. Root controls later product integration,
source-cold qualification and complete regression.

The small driver tests use real temporary Git trees to validate snapshot
admission and byte/mode/untracked/symlink refusals. They do not execute native
code or prove the remote component result. This harness does not change default
activation, deploy a service, delete legacy code or claim whole-stack closure.
