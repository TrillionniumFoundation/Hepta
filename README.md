# Independent Core/Plan R3 interpreter development gate

This minimal harness tree is not a Hepta product branch. It checks out the
published `4b19af89a766593f7d5f1cc2db256e81aba7afcb` source independently, verifies
all 3153 original Git blobs and modes and the complete tree, then applies only
the frozen 27-file R3 source packet `cd2bbecffd0123da4d45d1c7cc2222df5676de51`.
The original checkout HEAD remains 4b19; the driver records the actual candidate
content-tree identity separately. No future product commit is fabricated.

The actual interpreter must be CPython 3.14.4 on Linux x86-64. The original
669494-byte compiler input `81b6fad94493546b5bf3f858248f25b19aded88bf8f3aaad18140aa317dac109`
is explicitly retained DEVELOPMENT input, independently compiled against the
six current component sources. This scope does not run or inherit a current
cold report. Original inner 20-second compile and test limits remain in the
unaltered project implementation.

The three independent runtime steps are:

- The complete current 54-control Core/Plan, original checker and two held-owner
  contract panel. The existing observed runner is unchanged except that it
  receives the actual source checkout path explicitly.
- The full 123-control caller qualifier: current Core 22, original machine 51,
  and original Core 50, with all six actual selected Code/ELF/Plan/Core images.
  The original 1800-second external supervisor is used byte-for-byte. No group
  is omitted, split or assigned a larger deadline.
- All original 44 Plan callers, with the selected actual Plan and all four
  retained Plan policy bodies forbidden, through the unchanged public qualifier.

All three stages run after successful preparation even if an earlier runtime
stage fails. Each receives an independent original 1800-second workflow step
bound. The 100-minute Actions job bound allows three separately bounded steps
and setup/evidence retention; it does not enlarge any test or caller deadline.
No test body, expected lifetime trace, skip policy or original assertion changes
in this harness. Source/resource, tool and retained compiler records are checked
again at completion. Raw stdout/stderr, original result files, actual compilation
receipts/images/manifests and installed-wheel evidence remain in the artifact.

The original 4b19 actual CPython 3.14 Plan failures and every prior R2/R3 result
remain separate evidence. Authorship, static validation or a successful run of
this development harness cannot establish matching-current cold qualification,
whole native backend closure, default activation or legacy deletion.
