## Archive and failure preservation

The original allowlisted collector preserves successful, failed and interrupted
records without changing their outcome. It records every retained file's bytes,
hash, type, mode and nanosecond timestamp, and fully rereads the archive.

After the original upload, the separate lossless-copy stage may recompress the
entire original tar byte stream using XZ. It verifies exact decompressed tar
identity, member observations and unchanged original gzip/manifest/receipt.
It does not rebuild the payload from selected filesystem files, split the
original artifact, use range delivery, or change any qualification result.

The additional raw-text artifact includes only collector-owned declared roots
and named metadata. It has no promised size and may contain only available
metadata. Its upload success is not a test pass or proof that every desired
diagnostic exists. The complete original and lossless archive remain the
authoritative retained payloads.
