## 可核验结论

正式验收保留并完成 54 个 profiles、10,224 个可达公共状态、122,688 个
state-arm cells。原 native 两个比较臂各实际调用 42,480 次，总计 84,960 次。
campaign 外层计时为 101.028519050 秒；这是本次审计执行成本，不能直接作为
部署净收益估计或某个控制器的单次产品延迟。

从全部终态状态结果独立重算：

| 比较 | 结果 | 可支持的解释 |
| --- | --- | --- |
| 动态与固定数值偏好 | 6,068 个状态偏好数值改变；6,444 个状态候选值改变；动作变化 0；外部完整策略价值变化 0 | 数值通道已经参与计算，但在本轮全部可达状态中未产生额外行为或任务价值 |
| 当前后验与纯 prior reset | 第一动作严格 regret 出现在 188 个状态；完整策略严格 regret 出现在 244 个状态 | 丢弃可利用的信念信息会损害这个有限模型内的决策，且第一动作指标低估了完整策略差异 |
| 动态 NDU、same-objective、exact oracle | 全部状态动作、同目标候选值及完整策略值一致 | 有限模型内数值和选择实现一致、该目标的优化差距已闭合 |
| ordinary MPC 与动态 NDU | 全部状态动作及外部完整策略值一致；内部候选值在全部 10,224 状态中不同 | 本轮任务价值可被普通控制器完整复制；不能说它们内部估计的是同一个数值目标 |
| 2×2 factorial | 所有状态、所有 profiles 的偏好效应与交互项为零；纯信念与联合冻结结果相同 | 旧联合干预中的本轮损失可归于信念丢弃，而不是数值偏好冻结 |
| model-optimal fixed | 动态策略相对注册固定策略类：49 profiles 严格改善、5 持平 | 存在一般状态适应价值；这不构成 NDU 独有收益 |

其中 adaptive 与 misleading 各 18 个 profiles，纯信念干预的完整策略 regret
均严格为正；fixed 家族的 18 个均为零。但是 fixed 家族只有 5 个 profiles
满足“最佳注册固定策略与最优完整策略值相等”，其余 13 个仍存在一般策略改进。
不能仅依据环境名称把全部 fixed 家族写成“固定策略足够”。

## 2×2 分解足够回答什么

令 `B=1` 为使用当前后验、`B=0` 为每次重置初始 prior；`P=1` 为动态数值
偏好、`P=0` 为初始数值偏好。四格为：

- `V11`：dynamic NDU；
- `V01`：prior-belief-only；
- `V10`：fixed-preference NDU；
- `V00`：历史 no-adaptation，明确为联合干预。

四个完整策略始终在相同 true law 和动态外部目标下计分。条件信念效应为
`V11 − V01` 与 `V10 − V00`；条件偏好效应为 `V11 − V10` 与 `V01 − V00`；
交互项为 `V11 − V01 − V10 + V00`。这足以隔离本声明模型中的两种策略输入
干预。完整策略评价还保留了策略引起的后续资源与可行空间变化。

它没有识别现实中的潜在偏好参数，也没有唯一地把所有收益分摊成两个互不相关
的“机制贡献比例”。一般情况下交互项必须保留。本轮交互为零是实测结果，
不是协议强制。两个 scalar ablations 与两个 native 臂还使用不同计算后端；
本分解可用于共同目标的模型价值，不能直接作为物理运行时间的因果分解。

## 最强固定策略与 exact tie 的范围

本轮最佳固定策略的候选类只有三个：始终偏好 direct、cache-0 或 cache-1，
均保留原来的可行性 fallback。每个已知 profile 在首个观测之前依据声明 law
的 ex-ante 完整目标选一个策略，并保留全部候选选择成本。这个参考不覆盖
所有固定程序、预定动作序列、阈值策略或未知生产流量，也不是一个对所有
profiles 都统一最优的固定策略。

exact tie 说明求解和实现一致；两种实现求同一有限问题的最优值，本来就应
持平。ordinary MPC 连内部目标都不同，却在全部可达状态产生相同动作，这
进一步说明本轮行为不需要 NDU 特有的递归风险或数值偏好结构。候选数值
改变不是性能收益；完整枚举的状态和相关前缀也不是 10,224 个 IID 实验样本。

misleading 环境的信号反向相关率已知，正确 Bayesian 后验能够利用其信息。
它与错误后验干预可以检验有限模型中的误信后果，但不证明能够从未知噪声、
失准反馈或突变环境中自主辨识并恢复。信息获取付费动作也不在本轮动作集中。

## 原始 native 证据的独立复核

`verify_native_frames.py` 未调用被测 Python helper 或执行被测 binary，而是
从冻结原 Rust 规范另写整数与字节序列化规则。`NATIVE_FRAME_AUDIT.json` 记录：

- 108 个 native sessions 全部核验通过；
- 84,960 个 evaluation digest 全部独立重算一致；
- 339,840 个 recursive evidence digest 全部独立重算一致；
- 170,028 个原始请求／响应／hello frames 的哈希一致；
- 20,448 个 state-native 决策的调用区间无缺口或重叠，最后根节点响应被记录的动作和值消费；
- 108 个正常退出以及调用、计时账本一致；
- 230 个冻结研究文件、121 个构建输入和 112 个原始非 manifest 文件，以及 admitted binary/manifest 身份匹配。

这些是源绑定的本地原始记录验收与独立内部复算，没有形成外部同行评议、
硬件执行证明或新的物理任务收益结果。失败的科学优势判据应明确保留为
负结果；真实部署、参数学习及新机制所需证据应继续列为开放事项。
