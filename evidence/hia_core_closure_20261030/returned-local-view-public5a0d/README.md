## Source change and identity

The bounded source adapter now composes one same-mode returned byte loan with
a local View through the existing explicit v8 Core. The existing checker,
lexical Resource IR and canonical Core admission remain on that path. Parent
capabilities survive shared copies, exclusive moves and CFG edges until the
last dependent child is ended. Explicit drops, branches, loops and early
returns have actual observations. There is no new Core schema, execution
Machine, source route, fallback or production-authority flag.

This finite profile requires one same-mode direct byte-borrow formal in the
returned call; other arguments are scalar. Multiple borrowed formals, nested
call or View origins, aggregate borrowed formals, stored or escaping View
returns, foreign lifetimes and asynchronous lifetimes remain outside it.

Only ten source files changed relative to public b121. The source publication
receipt and the original ten-file raw Git export, modes, blobs and full-index
patch are included. Original local source `0d077885cc4be0b8ee96a012d7d6d2e51d1d2ace`
has the same tree, but has local parent `31736998decf7fe952617fd219130ee3a5048a9e`.
It is not relabelled as this public commit. The earlier local and intermediate
source qualifications remain separate historical records.

The reused full checkout was clean at public b121 before switching to public
5a0d. All **7,699 tracked files** then matched the new raw Git tree in bytes and
Git modes. Full source inventories were checked again before and after each
actual public run. This is source identity coverage, not a claim to have tested
every behavior of those files.

qualifier's original `main` exactly once with its original `--output` argument.

## Remaining boundary

This package qualifies only the exact public5a0d finite selections described
above. It does not claim that an official full hosted release has passed, and
does not qualify subsequent workflow or environment fixes. Prior official
failure records remain failures under their original source identities.

Python remains the production admission and execution authority, and the
optimization policy remains `no_change`. General memory and provenance,
arbitrary recursive ADTs, complete initialization, escaping or external
lifetimes, cancellation and full cleanup, general ABI callbacks or threading,
all historical migration configurations, independent agent efficiency,
representative performance and physical devices, whole-language soundness and
backend refinement remain open. None of the 27 original strict P0–P7
obligations is promoted to closed by this bounded source increment.

The final archive manifest and full-stream readback bind every retained path,
mode, byte size, SHA-256 and Git blob ID. Its ordered transport parts carry the
same complete archive identity and add no execution claims.
