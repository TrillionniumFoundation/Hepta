## Why the repair was needed

The existing qualification workflow and unified qualifier selected a real
Clang executable under `CLANG`, but did not synchronize the existing
`HEPTA_CLANG` alias consumed by the native convergence class. On the earlier
official source, the candidate and standalone populations therefore included
two skipped convergence methods. The original no-skip gates correctly failed.
Those original failed runs, quiet-versus-verbose attribution boundaries and
local red controls remain separate historical evidence.

This four-file repair sets the existing alias alongside the selected compiler
in both environment constructors. It also strengthens two existing regression
methods so an absent or stale ambient alias cannot hide the omission. Test
decorators, no-skip requirements, the compiler itself, Core semantics, runtime,
Machine and the canonical safety selector set are unchanged.

The original local repair `29b2409a75c5f0df082c9ae64e993a0879f929c7` has the
same tree and the same public5a0d parent. Its local observations remain local.
The original four-file export, raw Git modes and blobs, patch and public
publication receipt are included; no old local receipt is renamed as public.
