## 本轮实际修改

### P0：版本身份与统一准入

公共 byte-swap 变换保留 primitive v7，拒绝静默丢掉 composite 的结构化身份。NDU 的准入范围仍明确限定 primitive v1–v6，不能因为公共 API 扩大支持就自动扩大候选合约。变换前后都经过同一 Core 验证入口，v1 的 fill-loop 只有实际引入 v2 操作时才升级，v2–v6 保留原版本。

C 资源契约新增统一、有界的文本/文件入口。原先普通 JSON 解析会把重复的 `access: read` / `access: mut` 静默变成后者；实际修复前探针确实因此接受了写指针函数。新入口在创建值图前拒绝重复键及转义后的同名键。API 区分 `None` 与显式空对象；复制时只接受内建 JSON 类型，用身份比较避开自定义 metaclass 方法，并只序列化脱离调用者的新图。它不承诺对并发修改提供原子时点快照，也无法恢复调用者事先用其他解析器丢掉的重复键。

### P1、P2：独立资源执行

Rust 复用既有 Machine，新增 fill、copy、move_within、swap、copy_range、fill_range 六类字节操作。范围检查先检查 offset，再用 extent-offset 检查 count，防止加法溢出；空区间仍验证端点；同 owner 移动覆盖重叠方向，跨 owner 复制使用安全 Rust 引用，未加入 unsafe 或随复制长度增长的临时缓冲。

执行 profile 为 `cfg-call-byte-owner-bulk-v3`。整个模块先检查能力集，未执行的 helper 也不能夹带不支持操作。chain 运行、直接 nominal/composite 输入和公共资源句柄仍未纳入此执行 profile。正常、trap、预算终止和分配失败继续使用既有账本语义；宿主容器释放不会冒充语言层 owner.drop。

冻结运行完成 **1,460 次 Rust/Python 单 Core 完整账本对照**，分解为 124 + 105 + 1,231；1,231 已含新增 fill-loop 的 168 次，不重复加总。另有 **60 次真实 native bulk 结果/分配器/abort 控制**，输入与上述账本语料部分重合。步骤数在同一 Core 的两个解释器之间比较；优化前后不要求相同步骤预算行为。这些是有限实际执行证据，未被称为全语言 soundness 或后端精化定理。

### P3：第二个真实候选及 no-change

新增注册规则 `full-view-fill-loop.v1`。它只接受从真实零常量开始、以同一 mutable view 的实际长度为上界、单位 checked 步长、写入不变 u8、唯一入口/回边且没有其他 body 副作用的循环。最终 index/condition 不能逃逸，length 可以逃逸并被保留。完整 Core 重验，模型的声明不能替代匹配条件或执行证据。指令预算、宿主中断和宿主分配失败等价性明确排除。

NDU 准入记录 pass、基线/候选 Core、实际原生产物、验证/测量 evidence digest、真实上游 evaluator 结果和付费成本。测量策略升级为 v2：**两个完整原生产物相同就拒绝 eligibility**。旧 v1 报告保持原样。

实验执行器还修复了外层先杀 CLI、可能遗留独立进程组的问题。新的同步 ContextVar 期限在工具轮询及阶段边界检查，由实际进程管理者清理和保留可取得的部分输出。没有异步 SIGALRM 抢占，没有硬实时保证；缺失、中断、过期或偏离固定协议的报告会停止后续轮次。相关 52 项开发控制测试通过后，又包含在冻结集成回归中。

### P5：真实模块与成本分母

实际使用固定上游 `AndersKaloer/Ring-Buffer@8de8fff55a0baee4fef2a1c6a82d258a27c3c0ba`，原始 C 和头文件保持不变。其一种列出的构建配置下，**9/9 函数体完成 Hepta 迁移，22/22 活跃项目声明有处置；9 个 C ABI wrapper 单独计数；留在原 C 中的函数体、拒绝和未处置函数体均为 0**。这条路径使用 Hepta 受检核心、Rust 后端和调用者声明的 record-view 契约，未声称自动恢复任意外部指针所有权。

状态测试覆盖 8 个容量，每个 2,048 步，共 **16,384 次转换**。**65,544 对入口比较 = 原 C 65,544 次 + Hepta 65,544 次 = 131,088 次实际 native 调用**；比较返回、独立 deque oracle、持久字段、每个 backing-store 字节、哨兵、输入不变性和指针身份。另有 9 个边界拒绝、6 个 owner 客户端样例（含 2 次真实分配拒绝，最终 live allocation 全为 0），布局核对及已实际编译的错误实现负控；错误实现被完整 oracle 拒绝。

人工契约原文 1,989 字节、canonical 1,028 字节均保留并绑定 hash。自动资格耗时内部 **19.441099 秒**、完整 CLI **20.440978 秒**。人工契约编写、审查、维护工时仍为未知，不能由自动工具耗时推导低人工成本。

### P6：实际原生版本生命周期

新增 NativeVersionDispatcher：真实后台 Clang 编译、verified Core/LLVM/ELF 身份检查、sealed memfd、generation CAS、逐调用 pin、旧候选排空、回退、取消发布和关闭。最多两个版本、一个后台编译任务，入口限定同质 i32/u32 标量；候选为基线或 exact swap rewrite。取消会撤回发布，已有编译依照原超时边界清理，不声称瞬时抢占。

**9 项实际 native 生命周期测试已计入 149 项 Core/NDU 组，不额外加到总数。** PID FD 暂停/恢复真实子进程，观察切换期间的版本与文件描述符生命周期；没有内部 loan 事件握手，因此不声称已经观测任意活动借用时点。每次调用在独立子进程中执行，资源私有；跨调用外部借用、回调、共享状态、持久 worker、进程内热补丁和生产更新开销尚未资格化。

## 固定性能实验：收益未成立

协议在源码提交前固定：两轮 fill-loop、一轮 swap；每轮 31 对样本，每侧每样本重复完整语料 10,000 次；fill 16 输入，swap 20 输入。共 **32,240,000 次 timed native 调用**，另有 104 次 untimed 单例正确性调用。没有去掉样本、放宽 MAD 5%/收益 2% 门槛或重跑直到通过。

| 实验 | 基线中位数 ns/调用 | 候选中位数 ns/调用 | 相对 MAD：基线/候选 | 内部付费/完整 CLI 秒 | 决策 |
| --- | ---: | ---: | ---: | ---: | --- |
| fill-loop-1 | 69.128687 | 61.008000 | 20.940% / 20.095% | 5.021830 / 5.170952 | no_change |
| fill-loop-2 | 105.395206 | 102.279769 | 10.972% / 9.278% | 2.806605 / 2.949834 | no_change |
| swap-control | 23.153400 | 23.990410 | 13.667% / 17.221% | 2.036050 / 2.205122 | no_change |

以上只是描述性计时。两轮 fill 的不同 Core 和不同 LLVM IR，在相同 Clang 下得到完全相同的 15,480 字节产物，SHA-256 为 `9060fcb2df0d51a45c12ff426bc02bcbf0553c6ac3cf3c5f8d77c6534b9f8b73`。swap 两侧也相同，为 15,432 字节、`527992d971d479b12a0a8ef033745527f36764df081bc78ba4ac3d0ee94421d1`。这不能归因到未经观察的某个特定 LLVM pass，但能确定本轮变换没有带来不同的原生程序。

临时 .so 已由测量器在执行后清理；产物相等依据的是测量器实际执行前后取 hash、编译和执行回执。之后的只读审计没有重新读取已删除的二进制。完整 Core/LLVM IR 文本保留；所选工具身份也不代表整个宿主及所有动态库都已得到独立认证。

三轮各自的两侧 MAD 全超过 5%，固定调用 horizon 下也没有覆盖搜索成本。NDU 均实际返回 abstain。内部付费时间合计 **9.864485 秒**，完整 CLI 合计 **10.325908 秒**；工程实现、模型推理、工具安装、evaluator 构建、能耗及维护成本不在该数字中。新规则正确保留基线，**没有原生加速结论**。

真实 Ring-Buffer 的三个描述性 Hepta/C 中位数比值分别为 **0.740983、0.625515、1.589138**。第三项为退化方向；三组相对 MAD 范围 **24.007%–49.971%**，且是 GCC -O2 对受检 Rust -O3 路径的七样本对照。因此前两项也不能当作可重复加速或 Rust 优势证据，全部样本原样保留。
