存储借用尚不支持通用 trait/outlives/HRTB 或与类型泛型、所有权 ADT 的任意组合；
C、独立顺序／并发 IR 和 HMIR 对该新增 profile 拒绝。I/O 的独立 IR 也拒绝整个
未支持 profile，包括未使用的类型声明。任务树与 I/O 尚未合成为通用 executor，
也没有树级 I/O 取消或统一全局预算。错配 reactor 消耗完成票据时，原始 buffer
仍由原 reactor 持有至 shutdown；这项有界容量滞留被独立复现并保留为限制。

板级执行范围为 QEMU 8.2.2 的 Cortex-M4 mps2-an386 模型。报告保留可提取的完整
ELF bytes、48 个向量、段／符号、实际 UART 输出与完整命令；不等于物理板、DMA、
GPU、硬实时或中断资源健全性证明。volatile 不提供原子或内存屏障语义。
