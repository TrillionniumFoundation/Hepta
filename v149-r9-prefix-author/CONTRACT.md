# R9 private generation and size/pack prefix

This is an authoring package for one ordered prefix. It has not generated HIA,
compiled an image, packed or executed an ELF, called a VM, or created its product
root. Root is the sole launcher after reviewing the exact launch record.

## Fixed lineage and the new asset

The input tree is the recovered, independently verified **3180-file** tree
`4c62be4ed66ff107fa6f88c6131313a354868bd9`, containing **98,471,253 bytes**.
Its lineage is actual R19 plus the five frozen u32 files. It is not the prepared
R20 tree. The tree, ordinary compiler `SOURCE`, public R5 component pins, prior
R8 files and all prior failures remain unchanged.

The candidate is the frozen R2 word64 author, blob
`8dde3a64f7388f81f8996888c97d43def2b336db`. Its original module is retained by
identity. The execution copy changes exactly two top-level path expressions:
`ROOT` points to the recovered 3180 tree and its own `SOURCE` points to the new
external asset
`/hia-r8-r9-execution-20261114-dda7/generated/file_render_checker_word64.hepta`.
The complete inverse reproduces the original module byte for byte, including
every function body. This does not rebind the ordinary compiler's `SOURCE`.

The original generator main executes once, followed by its original `--check`
main once. Both execute in separate fresh 3.14.4 children. The generated
`word64_projection` is retained in full: original 107 functions, 1456 blocks,
6664 operations; expected transformed 107/1456/6347; 317 removed identity casts;
the complete edit log and its inverse; unchanged external f0; and the unchanged
complete Core verifier. These counts are preconditions to be checked against
the actual reports, not completed observations. No new HIA or image hash has
been predicted or filled into the author plan.

After both actual owners and reports pass, their complete bytes and the actual
asset bytes, mode and seven stat fields form `CANDIDATE-BINDING.json`. The two
reports must be byte identical, and `--check` must leave the actual asset's
seven stat fields unchanged. Those actual bindings are read again before the
compile and at prefix finalization.

## Storage and boundaries

The fixed new product root is `/hia-r8-r9-execution-20261114-dda7` on the root
filesystem. Its parent device/inode/mode are fixed in the plan. The original
**3 GiB entry floor** remains; the original size stage's separate **234,881,024
byte** reserve remains. Expected new raw and metadata storage is conservatively
bounded for planning at **256 MiB**. This is a planning estimate, not truncation
authority. No old source tree, runtime, input, failure or archive is moved or
deleted, and neither a full source/runtime copy nor a second archive is made.

This prefix is private generation plus size and conditional packing only.
Public R5 continues to reject this candidate. Matching current cold,
ordinary-encoding qualification, semantic Native162, all six original VM cases
at their original 10M fuel, aggregate kernel130, observer build, seven pipeline
VM cases with six full frames, and two last-byte controls remain separate.
The later four groups are mandatory and not waived by delivering this prefix
first. No previous PASS transfers to the new candidate.
