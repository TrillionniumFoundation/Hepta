# Independent R11 predicate observation readback

This author package has not run its reader. It binds the completed R11 boundary
owner, including the original Root outer and the actual independent prefix
proof. It launches no product, generator, compiler, native image, or VM.

The reader preserves twelve guard functions from the actual boundary support
and four complete functions from the actual R11 prefix reader. Their full
function bytes are checked during assembly. It reads the original 6,777-file,
948,620,735-byte source/runtime/control domain, all author and fixed controls,
every file of the actual boundary/outer trees, and every referenced buffer
again at its use. The only acquisition at author time is the fixed metadata
layout plus the explicitly pinned small control/result files. Authoring does
not stand in for that future complete payload readback.

All 1,806 case pairs and 3,612 recorded invocations must be present in order.
The 1,056 scalar pairs have no physical buffers. Each of the 750 full-function
pairs has two actual logical views before and after each version, giving
6,000 complete logical spans. Shared-owner cases preserve two observations
of the actual single owner; no synthetic source/output buffer is invented.

The full HIA texts are parsed as data, canonically encoded, and compared to
the actual three-link Core projection proof. The four recorded fragments
must be exactly the selected pure suffixes of these full programs, including
their original SSA operands and terminators. The copied independent case
factory supplies only the fixed inputs and two scalar character predicates.
It is not a replacement lexer or identifier implementation.

The structural trace recognizer consumes the recorded operation names,
output SSA names, depths and effects. It recognizes their position in the
fixed Core CFG and reconstructs operation, call-entry and terminator ticks.
It does not execute scalar HIA operations or choose branches by evaluating
their predicates. Empty-block cycles are rejected rather than guessed. The
fixed f16/f79 call closure has no block beginning with an outputless operation
and each function's produced SSA names are distinct, allowing recorded output
names to distinguish possible nonempty successors. It still rejects any
ambiguity observed at readback. No claim of independently reevaluating every
pure runtime value is made.

Recorded buffer effects are checked against the complete real preimages,
including successful writes already observed, aliasing, view/owner expiration,
write permissions and the first bounds error. The byte replay does not call a
provider, execute HIA or synthesize an observation. Each actual predicate value
is additionally checked using its preceding recorded byte load, or its explicit
scalar inputs. All real after bytes, untouched bytes, public error fields,
resource counters, call counts and original R10/R11 effect order must agree.
The original Machine, observer and producer are fixed source authorities.

One original 180+3 owner, its raw and returned receipts, full request and
environment, and the actual 1800+3 Root outer must all close. The VM limits
remain 10,000,000 steps, 1 MiB and depth 128. Reader success would mean only
PASS_INDEPENDENT_R11_PREDICATE_TERMINAL_ONLY. It cannot grant the original eight
groups, whole-native or matching-current-cold qualification. No observed
failure, missing file, incomplete span or exception can be filled or retried.

The eight-group successor must consume both actual independent proofs: the
already completed prefix proof and the future actual boundary-reader result.
The latter identity is deliberately not predicted by this author package.
