# Native Core emitter owner

This owner moves all six original `_Emitter` method bodies in
`hepta.hia_program_native` into a checked HIA continuation image:
`__init__`, `ordered_blocks`, `label`, `function_symbol`, `wrapper`, and
`render`. The original AST is preserved independently in
the text fixture named `hia_program_emitter_v76.py.txt` in `tests/fixtures`.
Runtime selection never
imports the authoring compiler or evaluates those original bodies.

The HIA image owns the complete method control tables, branch decisions,
generator suspension, foreign effect permissions, exception transitions,
temporary retirement, and named-local retirement. The original source and
compiler limits remain unchanged. The image is generated by
`tools/generate_hia_core_emitter.py` and the finite authoring compiler in
`tools/hia_core_emitter_control.py`.

## Exact foreign keyword-call boundary

The original constructor contains `Code(**code_options(machine_plan))`.
Preparing that mapping and invoking `Code` are separate HIA-issued effects.
The first services the actual CPython `DICT_MERGE` operation with the real
callable still on its stack, preserving mapping protocol, duplicate-key and
non-mapping diagnostics. HIA then retires the original temporary mapping.
Only a separately claimed call transfers the prepared exact dictionary and
callable into the interpreter operand stack. Holding that dictionary in a
bridge local through the entire call would change the lifetime of its values.

The representation port is a fixed straight-line opcode template for reviewed
CPython 3.12, 3.13 and 3.14 ABIs. Its call suffix is replaced by balanced stack
pops and a return; it does not execute arbitrary source, owner policy, `eval`,
`exec` or a runtime authoring compiler. A differing interpreter/opcode shape
is rejected. This mechanism remains an explicit CPython runtime dependency.
The physical-profile matrix is distinct from tests run on an actual version.

Ordinary positional and named calls also transfer their temporary operands
after HIA has granted the exact call permission. Borrowing those operands
until the later acknowledgment can incorrectly delay a Python callee's
parameter retirement, including the reversed named-local order in 3.14.
The transfer is part of the fixed foreign call, and an interrupted
acknowledgment still forbids replay.

## Selection, custody, and proofs

`HEPTA_HIA_CORE_EMITTER_MANIFEST` requests explicit selection. Each new public
operation rereads and binds manifest, HIA source, and executable image bytes.
`emit_program_machine` captures the selected owner, including captured
absence, for the complete operation. A nested callback cannot replace that
capability by changing the environment. The checker registry uses the actual
captured executable owner; a later selector or backing file cannot rewrite
the identity of an already admitted proof operation.

Each effect requires its exact issued permission and a native claim. Effects
and returned terminal values cannot be replayed. An interruption after a real
effect but before storing its acknowledgment retains an unknown frame; it
does not manufacture completion or grant another call.

## Building and qualification

`tools/build_hia_core_emitter.py` requires a completed matching-source cold
report before creating its output. The original compiler child limit remains
20 seconds. A retained development compiler is never a cold qualification.

`tools/qualify_hia_core_emitter_callers.py` runs the complete emitter component
module and the original 51 machine and 50 Core callers. Original IDs,
assertions and inner budgets are retained. Those callers explicitly select
seven native families: encoder, machine state, instructions, ELF, Plan,
`_Function` lowering, and this emitter. Development mode requires all six
dependency manifests; it cannot override a requested current cold report.

Permanent controls compare exact original results, error objects and observed
lifetimes; execute native frames against the independent HIA VM with complete
buffer/canary comparisons; check escaped generators and cross-thread final
references; inject lost acknowledgments after actual calls; bind actual
encoding proofs to captured and fresh images; and build and run an installed
wheel with authoring imports forbidden, isolated Python, no site packages,
and an empty PATH. Raw results, failed attempts and current qualification
scopes are retained separately as audit evidence.

## Remaining boundary

This is an emitter owner, not whole native delivery. Outer verification,
build/link/publication, process orchestration and other independently audited
owners remain dependencies. Byte ABI has a separate owner and qualification.
Python object ports and CPython exception/frame mechanisms still exist.
The existence of this image does not activate a default, qualify a joint
source tree, remove the interpreter, or authorize deletion of retained code.
