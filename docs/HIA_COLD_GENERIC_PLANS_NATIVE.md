# Native plans for the thirteen original generic cold families

These immutable source and assertion inputs retain the original signed,
scalar-cast, multiple-result, keyword, effects, CFG, bulk, loan, resource,
selection, tail/recursion, capacity and explicit-trap gates.

The component qualification executed 965 fresh full independent HIA VM
references before constructing a new B0, B1, B2, B3, M1, M2 and M3 chain.
B1 = B2 = B3, M1 != M2 = M3 and B3 != M3 were checked in that execution.
Each family then passed its complete original and modified native phase.
No previous interpreter return or previous native receipt replaces a live VM
execution. Fixed mathematical expectations and original structural Core
expectations remain additional checks of that live reference.

The static corpus contains complete original HIA source bytes, arguments,
view preimages, original resource budgets, expected return/trap categories,
original assertion provenance, compile-workspace words, output/short-capacity
requirements and exact source-admission errors. The default VM profile remains
1,000,000 steps, 256 call frames and 16 MiB heap; explicit original profiles are
retained individually. The keyword 80-argument and 32-return fixture, 249-return
loan fixture, original structural Core equality, actual 8,192 instruction
acceptance and 8,193 rejection, prior-store-before-trap state and real linked
ELF executions remain present.

Every runtime admission, diagnostic classification, Core projection, reference
execution, compilation, ELF inventory/link, machine call and assertion is
performed by native HIA tools. The two Python migration authors only extract
source and original predicate inputs; their development-time executions are
not accepted as final reference receipts. The plan composer serializes fixed
HIAQPL01 operations. The public cold master must load the resulting fixed
.hiacases plans and sealed inputs without running these authors.

## Phase contract

Each family has a pre-B0 reference phase, an original phase and a modified
phase. All thirteen reference phases must complete before B0 is constructed.
The native phase compiler import must be bound to that replay's B3 or M3.
Observer and linked-observer imports must bind to that replay's actual base
products. The tail reference phase publishes fifteen current-run VM receipts;
both tail native phases import those exact current-run publications. The
static reference_packet tool is distinct from those dynamic reference imports.

The passed bundle consists of 39 fixed plans (18,350,887 bytes and 320,944 nodes)
and thirteen source pools (52,522,730 bytes). Its descriptors provide
id/kind/family/label, complete plan hash, imports and publications. The exact
bundle and report hashes are recorded in the adjacent machine-readable index.

## Reproduction and preserved failures

Use source_pool(DATA, directory, families=(family,)) and references_plan(...)
or native_plan(...) in tools/hia_cold_cases_generic_plan.py to reproduce the
fixed plans. All source and dynamic reference import ordering is deterministic.
The final sorted tail import order was separately replayed for both labels;
the other 37 fixed plans equal their original passed v2 bytes.

The first native signed run used the normal-return checker mode for an expected
SIGILL. The actual trap and complete shared writes were correct. That failed
report is retained. The plan now invokes the original trap mode and checks
the same signal, output, workspace and stream requirements. The checker,
expected behavior and budgets were not relaxed.

The broad v2 component run passed all reference and both-label phases. The
slowest individual phase was 66.75 seconds under its original 180-second bound.
This is not evidence that the final two-worker, whole-cold 180 + 3 second
contract has completed: that combined master deadline remains a separate gate.
