## Local commands and source custody

The service-artifact companion supplies an actual existing strong-capture

An integrating full harness must append the same-current-cold component and
complete 112 qualifier without replacing the original 35-stage run or any
existing supplemental job. It must check complete ordered method IDs,
same-source cold custody, immutable fixture hashes, every streamed case and

The SQL-expression leaf must additionally retain its exact seven frozen

complete ordered case list. A correct original-only leaf cannot replace the
actual-image leaf; a prefix without the final report cannot be called a pass.

`hia_read` has no `request_key` input. A repeated call is a new read, enters
the owner again and uses the original deterministic cursor plus INSERT OR
IGNORE behavior. A failed read's report cannot be described as a durable
unknown-intent replay gate. Similarly, a process killed by `os._exit` has no
Python-finally counter record; do not fabricate one from a normal exit.

The weak registered Store guarantee remains limited to a still-live exact
generation and public retirement. It does not prove custody of an already
dead Store, an independently closed opaque DB or arbitrary provider internals.
All-input, all-interpreter-history and whole-project closure flags remain
false regardless of a finite component pass.
