# NDU feedback gates

This study continues Round 6's source-pinned dynamic-cache experiment. Its
unit-discount, linear, known-cost result remains a valid degeneration control.
It does not replace or reinterpret the previous no-gain result.

## What changes

The controller now sees only the current request, noisy signal, posterior,
resident cache and remaining resources. The environment owns the hidden demand
regime and future random samples. A cache action changes physical residency,
the cost of the next request and the remaining resource budget.

Every Bellman decision node submits all legal and illegal action witnesses,
including explicit abstention, to the selected value backend before choosing
an action. The original NDU kernel evaluates its existing Q32 affine recurrence
and candidate-selection API. Numeric state preferences enter immediate utility,
discount and the explicitly declared conditional-risk aggregation. A preference
digest binds those numbers but does not calculate them.

The finite model's conditional risk aggregation is part of this research
adapter. It is not a new upstream NDU authority, a general FBSDE implementation,
or a parameter-gradient estimator. `U` and `Z` are not used as parameter updates.

## Four gates

1. Hand-computable non-dominated action reversals bind observation, numeric
   preference, value, selected action and executed action. Keeping numeric
   inputs fixed while changing only their digest must preserve values/actions.
2. The online driver uses a real source-bound native workload. It executes
   allocation, transpose, eviction and matrix-vector work, checks every output,
   and feeds measured costs back only after the selected action. Future realized
   data and oracle answers never enter the planning interface.
3. Seven registered arms share information, resources, legal actions and the
   external scoring objective. A separately encoded exact oracle checks the
   same-objective controller and original native NDU. Three environments cover
   useful adaptation, sufficient fixed behavior and calibrated misleading
   signals. An additional gated arm measures stopping unnecessary calculation.
4. Reports distinguish numerical wiring, search/selection/consumption, model
   error and computation costs. The independent exact baseline may tie NDU;
   this is expected when both solve the same finite problem exactly. A claim
   of additional NDU benefit requires a separate measured advantage.

## Scope and cost

The native worker operates on generated affine matrices and validates its
outputs algebraically. It is a controlled real CPU/cache experiment, not an
unseen production task or proof of compiler superiority. The logical one-slot
quota measures packed allocations, not process RSS or whole-machine memory.

The outer episode wall includes startup, initialization, observations,
controller work, native RPC, validation/logging, cache changes, actual kernel
execution and cleanup. Kernel, native service and transport are nested
components of that wall. They must never be added again to produce a purported
total. Failed attempts retain partial state changes and actual elapsed work.

Offline training includes every candidate, including losers. Source retrieval,
build receipts, calibration, oracle audits and reports have separate observed
costs. Alternative standalone allocations may overlap and cannot be summed as
actual machine wall. Historical engineering, human review, energy and monetary
costs remain unknown. No full-lifecycle economic benefit can be inferred by
treating those unknowns as zero.

The protocol is frozen in `benchmarks/hia_ndu_feedback/PROTOCOL.json` before
final measurements. Final records contain exact source/binary identities,
planned denominators, original frames, all failures and explicit open gates.
All research artifacts retain `DENY_ALL` authority.
