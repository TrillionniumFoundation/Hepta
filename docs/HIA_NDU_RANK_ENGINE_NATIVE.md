# Complete native HIA rank engine

The engine makes one native entry call for baseline verification, typed option
capture, checked objective freeze, fresh candidate verification, observation
binding, per-candidate fresh proof, native identity/advice, scalar resolution,
selected fresh proof, and the final actual-cost gate. The parent loop executes
only fixed HIA roles, raw syscalls, MAP_PRIVATE allocation/growth and byte moves.
No host-language policy or effect dispatcher is part of this engine.

The native HIA packer accepts 21 actual roles, with the original 4 MiB per-flat
and 16 MiB total text limits. HI ANEP02 (without the space) has count21 at8,
21 byte lengths at16, mode at184, body at192; mode0 emits ET_REL and mode1 emits
the full callable flat. The policy chosen by the native build is the same in
both formats. The child transport bridge is a fixed source-bound mechanical
prefix; native owner and error wrappers are generated by their own HIA packers.

Actual gates: 74 native pack/atomic rejection/view controls; 17 complete calls
through the sealed 4461559-byte engine; 34 earlier complete no-native-budget
and owned-FD cases; and 10 earlier real-role differential integration cases.
The complete native calls include 32 candidates, 9 MiB and 72 MiB aggregate
owned arguments, exact entry-clock preservation, actual admitted A/B decisions,
two/three actual fresh proofs, original Unicode/Path errors, identity deadline
exhaustion, and charging every losing candidate's supplied cost once.
Reference-only observation replay is described in the actual reports; it is
not part of the product.

Input: HIANRK01/128, version1 at8, baseline byte count16, owned argument JSON
byte count24, remaining header zero, then baseline and argument bytes.
Arguments capture preserves Python JSON-owned typed values, last-value keys,
WTF-8, non-finite floats and full-width offsets. It does not relax Core/proof
JSON or the original per-program/node/depth domains.

Private six-Q engine output/control is at least65536. Context metadata is
normalizerFD48, proofFD56, sourceRootFD64, thresholdPtr72/length80, captured
integer-string digits88, and private interrupt pointer104. Context tickets
reserve3504..3559. A preexisting START4096 is preserved. O40/O16 return the
owned MAP_PRIVATE arena address/extent. On return0, result status4000,
kind4008, arena-relative byte offset4016, count4024, and full engine elapsed
4032 describe the terminal result. The rank context must copy it into its own
immutable result payload before unmapping the arena.

The context facade, shared mutable public Future values, background worker
integration and multiversion publication remain separate closure gates.
This checkpoint does not activate production or authorize cleanup before those
gates. All exact source, role, image and actual result pins accompany this file.
