# Original select extension: copied output fragments

## Result and boundary

The frozen revised compiler C1 now has an independent local machine-semantic
check tied to bytes that its actual native execution generated. Five real
compiler outputs supply five copied 35-byte selection fragments, one for each
of `u8`, `u32`, `u64`, `usize` and `bool`. Each fragment, placed under explicit
normalized SSA-slot preconditions, passes the existing supplied-ELF validator's
five obligations. The qualification has 25 SMT obligations and 200 finite
native observations of the already validated projection images.
Separately, 64 dynamic-input native calls run the five complete generated
programs and match the declared finite select examples. These are reported
separately from the projection proof and its 200 calls.

The original task's four-claim verification/evaluation/adoption gate remains
**HOLD**. This is a local conditional lemma. It does not prove the complete
compiler, the full generated programs, or the establishment of the slot
preconditions in arbitrary surrounding code. No Agent acceptance receipt or
adopted generation is created, and no existing claim is renamed or weakened.

The qualifier checks these complete bytes, applies only the compiler-source

It builds a seed from C1 through the identified current Core/direct backend and
runs that seed in the existing isolated bootstrap child on five ordinary valid

lengths, seed, raw process output and generated byte images are retained.

This native provenance has the existing seed trust boundary: the general
Core-to-machine refinement of that compiler seed is unproved. The observations
do not remove that obligation.

## What is copied and what is new

The checked fixture contains exactly one select operation. The qualifier binds
its three argument names and result name to their numeric SSA slots, then
identifies one actual generated interval containing:

1. The three `RBP`-relative loads for condition, true value and false value.
2. `TEST RDX,RDX` and `CMOVNE RAX,RCX`.
3. The actual `RBP`-relative result-slot store.

All 35 bytes are copied intact. The qualifier checks the source/result slot
offsets, rejects a missing or ambiguous selection site, and verifies that the
final linked proof artifact still contains the exact copied bytes. It does not
rewrite those bytes to match the specification.

A read-only GNU `objdump` pass over each complete output independently locates
the six instruction boundaries for that byte interval. Its command, executable
hash and full output are retained. This is a finite disassembly witness; the
SMT theorem still covers only the projection, and reachability and contextual
composition in every original input remain unproved.

New projection scaffolding provides three initialized, disjoint private stack
slots, normalizes their ABI words to the declared scalar widths, executes the
copied fragment, and returns its stored result. The independent validator
checks the entire resulting projection, including this scaffolding, exact
object/final-image binding, stack bounds and saved machine state. The proof
artifact is distinct from the original complete generated image.

The original input-dependent fixture includes parsing, loading and surrounding
program behavior outside this projection. Those parts are retained as bytes
but are not verified by the local lemma. The explicit normalized-slot
preconditions still have to be established and composed in a general compiler
correctness argument.

## Independent model and finite observations

The unchanged profile is
`hia.safe-core.unsigned-acyclic-single-borrow.supplied-elf.x86_64.v1`.
Each scalar proof records the exact Core, object and final image hashes plus
`subject`, `property`, `profile`, `assumptions`, `checker` and
`unproved_obligations`. Its obligations are:

| Obligation | Required result |
| --- | --- |
| Caller contract is nonvacuous | SAT |
| Machine memory accesses stay within the modeled bounds | UNSAT for a violation |
| SysV stack alignment and saved state are preserved | UNSAT for a violation |
| Every model input reaches a terminal outcome | UNSAT for a missing outcome |
| Return/abort/caller-byte observations refine scalar Core select | UNSAT for a mismatch |

The solver and native binding are pinned to `z3-solver==4.15.4.0`. The existing
Python Core/x86/ELF models, loader assumptions and hardware-refinement limits
are unchanged. All SMT queries and actual results are retained.

After a positive proof, each projection receives 40 finite hardware calls,
including both conditions, full-width values, boundary values and noncanonical
incoming ABI words normalized by the declared scalar interpretation. The
results match independent integer selection and width reduction. These 200
calls are corroboration of the projection only; they are not 200 executions
of the entire generated program and do not prove hardware ISA correctness.

A separate replay command checks an externally supplied artifact-manifest
hash, every retained file, the source-to-copied-interval binding, exact
projection bytes and the six proof fields. It then recomputes the 25 SMT
obligations from the supplied object and final image bytes. Replay performs no
compiler or native-image execution. The repeated obligations are not counted
as additional distinct proofs.

## Reproduction

Use Linux x86-64, GNU `ld`/`objdump`, libc and the pinned solver. Supply the three original
frozen files above; do not substitute the latest compiler.

```sh
python -B -m unittest tests.test_hia_original_select_fragments -v
python -B tools/qualify_hia_original_select_fragments.py \
  --original original-selfhost.hiaasm \
  --candidate candidate-selfhost.hiaasm \
  --patch fresh-select.patch \
  --output NEW_QUALIFICATION_DIRECTORY
python -B tools/replay_hia_original_select_fragments.py \
  --input NEW_QUALIFICATION_DIRECTORY \
  --expected-manifest-sha256 THE_RETAINED_MANIFEST_SHA256 \
  --output NEW_REPLAY_DIRECTORY
```

Both commands refuse to reuse an output directory and start their worker with
a fresh empty bytecode prefix. Qualification inventories project source bytes
before/after execution and records loaded source files. A local success does
not qualify another source revision; integrated CI should run both commands
from its own final checkout.

## Remaining original-task obligations

The old compiler rejects select input that C1 intentionally accepts, so
whole-domain equality is not the language-extension specification. The
original strict contract remains frozen. A future separately versioned
extension relation must establish the complete old-domain boundary and
preservation, correct new-domain admission/lowering, parsing and SSA invariants,
capacity/refusal semantics, resource and termination obligations, and the
required compiler-to-machine refinement. A local selected fragment cannot
discharge those obligations.

The original learner's full provider interaction, token ledger and bill remain
unavailable. This qualification creates new execution evidence and does not
retroactively fill that historical gap.
