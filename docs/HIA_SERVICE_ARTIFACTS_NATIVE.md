# HIA service artifact-input owner

This explicit owner executes the six original service methods `_profile`,
`_program`, `_signature_values`, `_native`, `_build_receipt`, and `_build_inputs`.
Their branch, loop, closure, comparison and return decisions are generated into
`service_artifacts.hiaasm`. The runtime accepts only HIA-issued object effects.
The metadata comparison generator stays lazy and short-circuits in original order.

The named-delete effect retires one lexical binding only after native permission.
It preserves the original signature route's early service release before the
held emission signature provider runs. Lost acknowledgements retain an unknown
frame and cannot repeat a deletion. Shared frame finish remains unchanged.

Select an admitted component with `HEPTA_HIA_SERVICE_ARTIFACTS_MANIFEST`.
Construction captures the image and exact checker custody before catalog or
storage work. Closing the service refuses new work through that held owner.
Ordinary unselected calls retain independent original functions. No default
native activation or legacy deletion is authorized by these component checks.

Storage, Core admission, context, emission signatures and SHA-256 are explicitly
retained subproviders. Native component execution is not whole-stack closure.
Development compiler inputs do not establish a current-source cold build.
The cold builder requires the full unchanged 180+3 second qualification and
matching source/manifest/image custody; compilation retains its 20 second limit.
The caller qualifier keeps all original Agent 48, namespace 35 and ledger 48
tests and their budgets, and poisons all six original bodies and dispatch aliases.
