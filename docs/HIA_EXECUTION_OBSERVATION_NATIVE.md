# HIA execution-result ledger policy

The source-bound eight-image candidate owns the complete retained
`validate_execution_observation` policy, its `need` helper and lazy unsigned
counter predicate. It checks return/trap/budget separation, exact profile flags,
field inventories, u64 counters, allocation/owner/loan/chain conservation,
external-root backing, heap limits, error classification and tick accounting.
The original complete function AST and whole original module are retained as
fixtures. No check, counter, evaluator limit or error priority is removed.

`HEPTA_HIA_EXECUTION_OBSERVATION_MANIFEST` explicitly selects the candidate.
Absent selection retains the original owner; an empty selector, missing source,
changed ABI or selected refusal never silently returns to it. Source identity
and immutable image admission are rechecked using the existing custody rules.
This does not authenticate an untrusted producer's claimed resource counters.

Seven public keyword values travel as one private tuple; all HIA modes retain
at most four bound arguments, 18 mechanical primitives and 64-instruction
units. Python objects, builtin set/dict/iterator mechanisms, exceptions,
allocation and image loading remain hosted. The HIA policy, not the bridge,
chooses each condition and callback. This is **not a native interpreter**, a
native-only installation, default activation or whole-project closure.

The strict builder requires the current complete matching-source cold report
before creating output. Explicit development compiler reuse is separate and
does not qualify new-source delivery. Native tests cover actual counter and
classification mutations, retained-owner-forbidden real runtime/external-root
callers, packet canaries, warm/missing sources and a real isolated installed
wheel with empty PATH and authoring imports forbidden. A separate caller gate
loads thirteen complete existing modules without filtering tests or weakening
their limits. Original and failed evidence is retained outside the product.

PASS with independent Core VM; eight real images compiled using the prior v83
compiler (explicit reuse); initial native mutation test PASS; five expanded
tests PASS; eight component/source/installed tests PASS in15.180s, including13

These are finite development witnesses, not whole-source formal qualification.
