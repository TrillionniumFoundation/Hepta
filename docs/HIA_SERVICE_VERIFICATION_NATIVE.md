## Control and effect boundary

The authoring graph has 446 ports and 26 modes: nine public workflows, twelve eager private comprehension/callback bodies, and five lazy generator bodies. HIA owns their iteration, conditionals, short-circuit destinations, handler continuations, yield/stop decisions and terminal sequence. Literal Python ports perform the original single expression or a mechanical object-protocol step. No selected port calls an old complete workflow or implements a business comprehension loop.

The original dynamic builtins and globals remain dynamic. The seven import capsules retain actual `IMPORT_NAME`/`IMPORT_FROM` semantics, original namespace identity and captured builtins. Their provider imports are not replaced by authoring-module imports. The externally overridable `sum`, `any`, `all`, `tuple` and other original callees are obtained at their original expression position. Core admission and execution, optimization solving, machine emission and linking, safe-core validation, hashing, Store persistence, external tools and the OS are still hosted providers. This controller does not make those providers native, prove arbitrary Python object equivalence, or close the entire product.

## Delivery and generator ABI

The only installed entry is the existing six-argument byte ABI, with 128 request bytes, 96 response bytes and 192 state bytes. All buffers retain canaries and complete receipt/state checks. Events are INITIALIZE, CLAIM, SUCCEEDED, RAISED, FINALIZE, RESUME_GENERATOR and THROW_GENERATOR. No unexpected effect is retried.

Each invocation has a DeliveryRecord and independent per-port and whole-invocation weak registered-resource facts. Whole responsibility survives individual port acknowledgements. Complete FINALIZE retires only that invocation's confirmed obligation. Unknown native or foreign delivery retains the actual associated resource and rejects later retirement; a speculative association alone does not assert an effect.

A lazy generator is a real Python generator for `send`, `throw`, `close`, `gi_running` and PEP 479. Its outermost iterator is acquired at original construction time. Its first actual advance creates the private HIA frame. Each advance creates fresh delivery custody; HIA reaches READY_YIELD, validates FINALIZE and reaches PAUSED before releasing the active record. There is no suspended active ancestor. A later legal resume obtains a fresh record at the actual PID/thread/Context. Original cells are shared where the original code captured cells; unrelated local storage is not retained merely to make a fixture pass.

Normal release returns from the shared driver before its success acknowledgement, inside the same whole foreign scope. This leaves actual traceback/back-chain retention observable and permits a destructor's real child loss to prevent the next entry. Exception stack decrefs use the explicitly captured public handled-exception ABI already used by Lease. No traceback clearing, inserted collection, metadata normalization, result compensation or warming loop is part of production.

A separate six-case original LOAD_FAST/LOAD_DEREF micro-domain, with and without an outer handled exception, records exact metadata and raw tracebacks before comparing the mechanical accessors.
