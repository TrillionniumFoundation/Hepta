## Explicit limits

The prepared-artifact driver and fixtures are test controls using a foreign host
compiler and Python oracle. They are not a native HIA runtime port. Restoring
controls alone establishes no new safety theorem or full delivery acceptance.
Native-only install, runtime/Agent ownership, module/build/linking, persistence,
original/modified cold bootstrap and real project gates remain open until their
actual combined source passes. Historical evidence indexes are restored at their
original pinned bytes, not resealed; an index by itself proves no archived payload
integrity and grants no program admission.
