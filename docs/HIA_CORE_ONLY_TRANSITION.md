The owner's removal decision supersedes the previous frozen-language policy.
There is no delivered high-level Hepta source language, AST/checker/front end,
source migration route, source parser native-port application or compatibility
package. `hia` is the sole installed command. The `hepta` Python namespace and
`hepta.hia.*` wire schemas remain stable HIA Core identifiers.

and the fifteen retained HIA applications retain their previous exact bytes.
