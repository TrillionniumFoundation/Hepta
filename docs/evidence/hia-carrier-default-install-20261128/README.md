## Binding and behavior

`tools/install_hia_carrier_compat.py` accepts explicit digests for the base wheel, native compiler, typed child bundle, and native stage19 publication. It checks every wheel member and RECORD row, captures real native source/image/seed publication bytes, builds only the closed CPython resource ABI, and compares both embedded policy images with their native publication. A fresh process performs the original typed child admission before installation. The final wheel contains the two ABI binaries, exact build receipts, HIA policy images, current capsule, and an installation pin bound to the actual destination. Pip installs that exact wheel; a separate reader verifies the complete installed inventory and RECORD before default execution and again afterwards.

`hepta/hia_carrier_default.py` recognizes only the exact package-owned target domain, its RECORD, current capsule and explicit receipt hashes. Explicit operator selections are never supplemented. The current binding retains these initial package snapshots before admitting or loading either extension and rechecks them through the ordinary custody path. Absent, relocated, mistyped, altered or late-mutated default data refuses.

The current Slot capture path is explicitly separate from the historical v6 source closure. A genuine Slot extension and receipt produced by the wheel builder admits the current source set, including `hia_native_host_support.py`. The original v6 call still refuses that changed set.
