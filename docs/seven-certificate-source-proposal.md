# Seven-certificate source-only proposal

`tools/core_seven_certificate_sources.py` defines the distinct
`seven-certificate-source-v1` protocol. It has no runner, write, Lean launch,
receipt, or admission API. Existing source validators and workflow remain
unchanged. All twelve obligations remain unproved; authority is `DENY_ALL`.

Original transport theorem cuts are 512, 783, 837, 1406, 2109, 2811, 3513,
4215. The first block is appended after the complete, unchanged SyntaxData and
byte-fact helper. The other blocks form seven certificates. These are structural
cuts, not measured execution bounds. No performance claim is made.

Connections and TransportRejections retain their complete separate bodies,
including original print placement, between explicit framing markers. WrongArm
imports only CertPart04 and its ancestors; its intentional extractor name
collisions with Connections remain in disjoint environments. Print subjects are
not local declaration owners. Expected print counts are 56, 547, 271, 54, 1164,
1298, 1297, 1297, 1297, 75, 1.

The validator extracts actual candidate declaration/body bytes, checks global
transport names and reference order, reconstructs the old transformed eleven,
and invokes the unchanged byte-fact and original-partition validators. This
checks five complete source/input bindings, 7685 definitions, 4215 original
transport theorems, 2975 auxiliary facts, 66 targets and ten negatives. Original
negative coordinates are preserved; current consumer coordinates are recomputed.
The manifest contains bounded framing, cuts, anchors, hashes and counts, not a
per-declaration map. Its serialized limit is 32768 bytes.

The returned object retains only the original exact-eleven and new candidate
sources. The old transformed generation is a temporary Python validation
intermediate, not a retained source tree. `validate_retention` measures actual
UTF-8 bytes, including every separately supplied execution, instrumented,
marker or evidence copy. Every future caller must provide all such copies before
writing or launching anything. This layer currently retains zero such copies.
The exact candidate totals 3,192,972 bytes; original plus candidate totals
5,593,354 bytes. The compact manifest is 20,819 bytes. The largest candidate
module is 550,810 bytes. These are source sizes, not execution measurements.
The unchanged limits are 2 MiB per source and 8 MiB aggregate retained sources;
retaining the third complete generation is rejected. Temporary Python heap is
not the retained-source budget.

Run the source-only counterexamples with:

```
timeout 180s python -m unittest discover -s tests -p test_core_seven_certificate_sources.py -v
```

No old, incomplete, oversized, partial, missing or timed-out receipts become
admissible through this module. Future execution would require separately
reviewed integration and fresh same-run receipts, under the existing budgets.
