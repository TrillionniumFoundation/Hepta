## Authored control boundary

Five public modes and two private generator modes share a 128-byte request,
96-byte response and 192-byte state ABI. The HIA author contains 98 claimed
ports. HIA decides all method branches, dict/list-comprehension iteration,
the two profile/document loops, constructor cleanup routing, exceptional
handler departure, generator suspension/resumption and terminal disposition.
Python ports evaluate fixed original expressions or perform the actual
object protocol operation requested by the current HIA claim.

The original five definitions remain byte-exact in the class. A separately
delimited append-only public tail captures those exact functions, their actual
local-layout tuples and builtins dictionaries. An absent selector calls the
retained definition through popped argument storage. Selected wrappers delete
their forwarding self/arguments before finish. Existing Discovery, Lease,
Capture, Slot, Inspection and peer proof tails are not replaced.

The init imports happen before selection calls; selection precedes catalog,
tools, identities, Store construction and None assignments. The cleanup try
starts only afterward. A failure of AgentStore itself does not execute the
later construction-cleanup block. The two candidate/ledger branches do not
add a ledger close. Cleanup evaluates the complete original bound-callable
list before invoking either callable. Original cleanup failure matching and
add_note lookup remain dynamic. close always follows the original finally
Store close, including a budget getter or close failure.

_profiles retains all eager dictionaries and original lookup order: 7
profile writes, 6 initial discovery JSON writes, 10 document put calls, and
the final macro/examples/diagnostics/manifest JSON writes. It does not lazily
construct only a requested resource. The large bodies expression uses one
fixed expression capsule at the path-root list comprehension; HIA controls
that list's iteration while the original enclosing expression stack stays
suspended. A caught StopIteration is consumed before a captured actual error
is raised, so its private transport does not become the error context.

_profile is the complete original check_profile call expression.
_program performs the original two-item get unpack and the complete
verify_program(decode_json(data)) expression.

## Lazy generator ABI

The original dynamic tuple and any receive actual Python generator objects,
not eager replacements. Iterator acquisition remains in argument evaluation;
body/Frame creation occurs on the first advance. Each advance has its own
DeliveryRecord, whole weak registered-resource holder and per-port holder.
HIA READY_YIELD is followed by an actual FINALIZE to PAUSED before yielding.
A later send/next resumes the same state using a new delivery record and the
actual current parent/thread/context. Throw/close take the original Python
generator exception path, with HIA issuing its exceptional unwind. PEP 479
remains the interpreter's rule. There is no creator-thread-only restriction.

This is a new, untested internal ABI. Qualification must cover an escaping
generator saved by a custom tuple/any, no-advance close, send(non-None),
throw identity, StopIteration conversion, retained traceback, cross-context
resume and original reentry rejection. No result from the older transaction
generator is substituted for these observations.

## Local lifetime and exception responsibility

Module-owned private ABI array classes and fixed release probes avoid
per-call type construction. The original runtime co_varnames layout is
captured from retained functions. A single real drive frame owns the original
local dictionary. Normal HIA release detaches that dictionary; its drive frame
returns before the release acknowledgement. Exceptional completion detaches
ownership without clearing the dictionary or traceback. The terminal result
is popped out of the Frame.

HIA-issued temporary-stack/exception-alias retirement uses the already
available CPython public handled-exception API. It saves strong pointer owners,
installs only the original caller/handler handled state at the designated
decref port, and restores the actual pending state in finally. It does not
rewrite name, obj, cause, context or traceback, and does not normalize GC.
The prior public-ABI diagnostic is background feasibility evidence only; it
does not qualify these new handler levels or asynchronous interruption
windows.

Whole and per-port resource holders are independent. A per-port ACK cannot
retire the whole method's observed facts. Initialization takes place before
the whole holder; pre-first-effect preparation failure does not invent a
returned provider. Same-Frame reentry rejects before a cleanup finally.
Actual child loss is checked before every effect, native entry and final ACK.
