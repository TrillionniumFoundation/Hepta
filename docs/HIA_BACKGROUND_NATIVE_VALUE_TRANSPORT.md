# Lossless value-capability transport for background freezing

This private native owner exports the already captured JSON-domain value graph into a sealed byte stream without applying serialization business rules. The controller then runs the actual owned-JSON capture and checked sorted freezer. This ordering preserves the original sorted-key integer/nonfinite error precedence and the later UTF-8 conversion failure. The public Future still holds its shared mutable result object; this stream is only an internal input to detached accounting and submit freezing.

## Interface

The fixed six-word export is `hia_background_value_transport`. Input is exactly 128 bytes, magic `HIABIQ01`, operation at byte 8, and an actual value capability at 24, 32, 40. Operation 0 creates a stream; operation 1 retries explicitly retained cleanup and requires all input capability words to be zero. All other input words are zero.

The private output view is at least 131072 bytes. The independently owned per-call context is at least 256 bytes: `HIABIC01`, captured actual value entry at 8, value context at 16, and context extent at 24. Bytes 32 through 80 are reserved for native cleanup ownership and actual PID; bytes 88 through 255 remain zero. A context is exclusive to one in-progress call. The controller strongly owns the value context record and the captured closure throughout the call and any cleanup retry.

The reply is 128 bytes: `HIABIO01`, status at 8, owned sealed FD at 16, full byte length at 24, actual seals at 32, private dependency/system detail at 40, and retained-cleanup indicator at 48. On success, seals are exactly 15 and the caller owns the FD; use offset-based reads because the write offset is at the end. On failure the FD field is all ones. Status 2 rejects unsupported private graph types/non-string keys; 3 rejects cycles; 5 is allocation failure; 6 is lifecycle/PID refusal; 7 is a failed actual value operation; 8 is an OS failure; 9 is a private invariant failure. Malformed envelopes/views return 0xfffffffd and preserve the public reply.

## Value and lifetime semantics

Only actual value operations 5, 6, 7, 19, and 23 are used. Every traversal node owns an independent nonce reference; each enumerated key/value reference is owned until consumed or cleaned. The implementation never borrows the value owner's internal arena pointers. It preserves insertion order, shared aliases by value, all integer digits, binary64 values, and WTF-8 string code points. Strings escape JSON delimiters/control bytes and preserve raw WTF-8; adjacent surrogate code points remain distinct from an astral character.

Finite binary64 values are written as an exact integer coefficient and decimal exponent using bounded arithmetic implied by the binary64 format. No rounding occurs in this transport. The existing qualified capture/canonical roles perform their own original conversion. NaN and infinities retain their value category until the checked freezer rejects them at the original point. No int-string digit limit, UTF-8 policy, node limit, depth limit, or aggregate byte limit is introduced by this private transport. The original BG/structure/freezer limits remain separate mandatory callers.

The native policy owns every temporary frame and its output FD. Real allocation and OS failures unwind the retained references and close the incomplete stream. A refused dependency drop is retained explicitly in the private context; further normal work is rejected until operation 1 retries that cleanup. It is never silently discarded.

## Qualification

The actual native product passed 329 smoke calls, including random binary64 bit patterns, 9 MiB strings, 100001-digit integers, aliases, cycles, and non-string-key cleanup. Another 266 actual transport → native capture → native sorted-freezer comparisons match original CPython bytes or exact exception class/message and Unicode span, including competing integer/nonfinite/Unicode errors.

Twenty-two control groups cover twelve actual frame-allocation failures, four separately labeled value-dependency controls, quarantined drop/retry, real kernel partial write/EFBIG and EMFILE, malformed/short/overlapping views, and 240 transports across eight threads with independent continuations. The HIA packer passed 24 controls. Policy compilation was performed twice by the qualified native source compiler with byte-identical output; the production object and shared image were generated by HIA packer and HIA linker. The readable mechanical source is checked separately.

The companion JSON contains complete source, product, and evidence pins. This qualifies the transport component; the full BackgroundOptimizer controller remains open.
