# Selfhost cross-feature qualification

`tools/hia_selfhost_feature_matrix.py` runs nine feature witnesses against a
freshly bootstrapped HIA compiler. It preserves the actual
`f0(readbuf,mutbuf,mutbuf)->u32` entry. The Core VM receives live disjoint
external roots and runs the exact admitted Core; no entry parameters are
removed. These finite observations do not extend the bounded profile.

| Witness | Core VM result | Declared bootstrap expectation |
| --- | ---: | --- |
| unsigned call and CFG | 17 | Accept and execute generated flat image |
| owned argument with scalar return | 8 | Accept, link generated ELF object, execute |
| signed helper | 0 | Reject |
| two scalar helper results | 17 | Reject |
| returned owner helper | 8 | Reject |
| returned loan helper | 8 | Reject |
| general helper name | 17 | Reject |
| general module name | 17 | Reject |
| general helper name plus two results | 17 | Reject |

All nine must pass Core admission and the Core VM with balanced local owners
and loans. Unsupported features are distinguished from invalid Core. The last
row does not assign a unique cause for refusal. A named module tests one
identifier, not a module graph or module linking.

The qualifier builds B0, executes B0→B1→B2→B3, requires identical B1/B2/B3
bytes, then uses B3 for every case. Rejection requires the actual compiler's
INVALID return and unchanged source/output. Acceptance requires retained
generated bytes and native execution with the expected return and unchanged
caller output. Owned ELF output uses an explicitly recorded GNU ld/libc link.
The disposable loader imports no HIA parser or compiler.

Run on Linux x86-64 from the exact checkout with a synchronized source contract:

```sh
python -B -m unittest tests.test_hia_selfhost_feature_matrix -v
python -B tools/hia_selfhost_feature_matrix.py --output /absolute/new/matrix
```

The output directory must not exist. `qualification.json` retains checkout and
source identities, B0 receipt and every generated compiler identity, each
source/Core identity and VM/compiler/native result, original stdout/stderr and
requests, a file-size/hash manifest, elapsed wall time and terminal status.
Every row must pass and source bytes must remain unchanged. An expectation is
not an observed result: read the invocation's retained report. Failed attempts
remain failed; a new invocation requires a new output directory.

This qualification does not establish all-input compiler correctness,
model-to-hardware refinement, a security sandbox, whole-language selfhosting,
or adoption authority.
