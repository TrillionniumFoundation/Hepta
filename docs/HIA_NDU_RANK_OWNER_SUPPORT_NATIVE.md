# Native rank report, snapshot, process and admission stages

These are actual native components for the remaining complete rank caller. They
do not claim that the full rank owner, background optimizer, public activation
or repository cleanup is complete.

The report role constructs all original objective/support/candidate/row/request,
native admission, selected proof, costs and final rank records. Canonical JSON
key ordering, signed 128-bit budget/margin magnitudes, full unsigned 128-bit
totals, Unicode code-point detail truncation and the zero margin on abstention
are retained. Measurement and output passes have no added aggregate byte cap.
507 actual report/snapshot checks passed, including all conditional record
branches, 128-bit extremes, escaped strings, a nine-MiB message, output guards,
and original detached snapshot order/queued-node/depth limits.

The snapshot role handles fresh immutable native JSON-owned arenas. It applies
the original dictionary/list detached-snapshot gate left to right before
structure accounting. It does not claim foreign class/cycle/mutation capture.
A selected subtree stops before siblings outside that root.

HIANRP01 has a 768-byte header and contiguous absolute-offset part table.
Actions 0..10 are objective identity, baseline support, candidate report, native
row, native request, native admission, selected proof admission, aggregate
costs, final rank report, JSON array, and exception. Mode 0 measures and mode 1
emits. HIANPR01 returns the u64 JSON extent at 8 and action at 16, with bytes
at 64. The output is unchanged on a short extent.

HIANVS01 has a 128-byte header: root at 8, raw bytes at 16, arena bytes at 24,
then raw JSON and its actual whole native arena. HIANVR01 returns status,
error ID, node kind, visited/queued counts and exact original exception JSON.
The original node budget is 262144 and depth is 64.

The separate rank child process variant uses HIANPS01/HIANPO01 and
hia_ndu_rank_process. It retains the qualified process custody, deadline,
cancellation, complete stream capture, direct-child reaping and process-group
termination. Fixed role 2 now invokes the actual hia-public-proof facade and
admits its existing image within 16 MiB; other role images stay at 8 MiB.
Role-2 input retains 16 MiB + 192 bytes, other input 8 MiB, and individual stream
caps 64 MiB. No original multiversion process role was changed. Actual native
packing/shared linking produced 172816 bytes with SHA
2ac9c3498ef17830345ff09a00898431aab1cec3298810c9012a8fe5a3a2b8c8.
57 process cases, 52 request/FD controls, 7 image boundaries and 5 pack controls
passed, including the real normalizer, full proof facade and P3 builder.
The readable 266-byte mechanical assembly matches the packed bridge exactly.

Admission adds actions 4 and 5, corresponding to ordinary/float-resumed
pre-objective-freeze checks. Successful status 4 means the preceding function,
generation, timeout, bridge-timeout and objective-shape checks have passed.
The owner must now perform the original objective JSON freeze, with its
captured integer conversion policy and Unicode/non-finite error order, before
resuming ordinary actions 0/1. No caller-provided frozen flag grants this step.
The prior candidate/observation and post-freeze option behavior is unchanged.
790 cases and 1393 actual calls passed against unchanged original statement
fragments, including 291 before-freeze checks.
