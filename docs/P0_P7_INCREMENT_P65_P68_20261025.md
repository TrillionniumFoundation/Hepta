## Mandatory safety claims

- `whole_project_blockers_closed=false` remains the only honest status.
- C++ L1 source candidate does not preserve arbitrary native C++ mangling,
  exception semantics, class ABI or memory safety.
- Rust source reference checks are required by P5 but do not prove independent
  LLVM codegen equivalent for arbitrary inputs.
- Both Agent workspace queries are immutable/read-only and cannot infer
  functional equivalence from an unchanged contract.
- A compiled object on a target architecture is not a target execution or ABI
  interoperability certificate.
- Any unsupported, unknown, skipped or unexecuted acceptance remains OPEN.
