# Native Future special-method truth

The truth component executes actual source-bound HIA methods in the same
Value arena used by the real canonical Future object and its native provider.
It preserves original direct Future wire profiles and the FP04 operation-31
native callback routing contract. This checkpoint is a component
qualification; final callback/worker fusion and the complete inherited
Future release campaign remain separate.

## Native dispatch and custody

The existing owner first resolves the real class and special method. The
truth role begins only when the registry mutex is released. Ordinary native
functions are bound to the actual receiver with operation 69. Existing
bound methods retain their binding. The role creates the real argument tuple
and invokes private classified operation 97 through the fixed sole Value
entry. No request supplies a code pointer and no host executes a method.

__bool__ must return an exact bool. __len__ accepts actual integer values and
integer subclasses, or one real __index__ invocation; the index result must
be an integer. Negative lengths raise ValueError before overflow checks.
Positive lengths above the host Py_ssize_t maximum raise OverflowError.
Default truth reads the actual stored numeric or container base of real
subclasses. A type name never substitutes for class or native object identity.

Returned exceptions are classified by operation 97's actual MRO result.
The original exception strong capability is preserved before temporary
method or argument references are released. Future reply kind 200 carries
that strong capability at offsets 72/80/88. Status 1 is Exception; status 2 is
BaseException outside Exception. Cleanup failure remains independently
visible at offset 120 while the primary exception stays delivered.

All temporary class, method, index and name references have real custody.
The existing quarantine protocol retains failed or unknown releases.
Expanded error-name storage uses actual mmap/mremap and records its exact
extent in HIAFQTN2; the original HIAFQTN1 still requires exactly 4096 bytes.
Full type names and the original 200-UTF-8-byte precision behavior are
compared against CPython 3.14.4.

## Packing dependency

The outer Future assembly still has its original logical cleanup slot.
That slot must now contain the actual two-role cleanup/truth capsule,
not the cleanup policy alone. The fixed HIA packer is
background_optimizer_future_public_truth_packer.hepta.

The HIABFTPK frame has a 32-byte header: magic, count 2, cleanup length and
truth length, followed by the two native bodies. Its mechanical bridge
routes phases below 1800 to the inherited cleanup body and phases 1800
through 2099 to truth. The capsule's workspace remains 128 bytes and no
caller-selected function pointer is admitted.

The qualified enclosing candidate retains HIAGFUP4 and 64 logical roles.
Its sole Value body is the independently qualified fifteen-role product.
Only Value, Future owner and the logical cleanup slot replace the frozen
managed-binder inputs. Original 4 MiB role and 16 MiB text limits remain
unchanged; exact compiler, body, native packer, linker and source pins are in
HIA_NATIVE_FUTURE_TRUTH_COMPONENT.json.

## Actual qualification

The 43 groups cover real numeric/container subclasses, native bool/len/index
methods, non-callable methods, original error order, long Unicode class names
and actual Exception/BaseException objects. The managed run uses the trusted
mask-190 native initializer and actual canonical Future construction. It
finishes every case by proving empty Value/provider queues and native
registry, actual owner closure and unchanged file descriptors.

Four further kernel notification groups refuse actual munmap at the fixed
code or Value syscall instruction. The original raised object and category
remain delivered independently of pending retirement. Every refused mapping
is verified live before retry and absent after one ordinary native entry.
The Value failure path can retain both the method-binding record and the
method-call record; the gate observes all actual records instead of assuming
a single one. Final native custody and file descriptors return to baseline.

The existing 43-group normal pass is not used as a substitute for final
inherited Future regression. Callback logging, worker submission and the
public enclosing runtime continue in their own integration work.
