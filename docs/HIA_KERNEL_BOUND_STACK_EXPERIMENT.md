# Native pre-lease dense xAPIC scheduler descriptor binding (HOLD)

A separate experimental typed operation, `x86.irq.dispatch_bound_stack()`, preserves both earlier raw IRQ ABIs. The fixed two-CPU CPL0 contract reads IA32_APIC_BASE (enabled xAPIC at 0xfee00000), reads the live MMIO APIC ID, requires ID 0 or 1, and reads IA32_FS_BASE as a separately provisioned trusted, aligned, low-canonical dense two-descriptor table root. The exact GS candidate must equal root + 32 * live ID before dereferencing the descriptor, acquiring its generation lease or changing RSP. The original guarded generation lease, canary, frame validation, release, and terminal IRETQ remain.

The trusted FS root and APIC mapping are boot prerequisites, not general resource authority. No user-mode FS/TLS contract, NMI nesting, sparse APIC IDs, arbitrary CPU count, page authority or concurrent descriptor mutation is claimed. This is an experimental candidate and does not change production locks.
