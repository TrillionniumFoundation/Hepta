# Native HTTP MCP owner checkpoint

The standalone HIA owner binds the admitted runtime configuration, Controller manifest, loopback listener and private token file. It captures the existing sealed Controller roles and owns the shared controller lease, request audit channel, HTTP connection records and session processes. Each legacy session has fresh MCP state; a global slot and generation allocation keeps audit leases distinct across sessions.

The current product is a partial integration checkpoint. Its 42 roles include the independently qualified HTTP header, framing, JSON, chunk and metadata facets. The exact original 522 HTTP admission cases passed on v4. The lease correction on v6 passed 64 overlapping requests, two sessions observing the same real SSH/systemd Worker job through its identical terminal result, and parent-only shutdown with owned process reclamation. The v7 common event stream passed actual frozen-runtime comparison for primary replacement, 32 shadow streams, inclusive resumption, the HTTP priming event and the 15-second keepalive.

Cancellation, duplicate request-ID routing, remaining HTTP transport edge cases and full final production integration are not yet qualified. None of these component receipts claims the full rewrite, native-only source release, final cold qualification, default install or installed rebuild is complete. Earlier failed private runs are retained outside the production source tree.

The private session process inherits the controller lock open descriptions needed by the job bridge. It never explicitly unlocks the parent lease. Public termination first reaps owned session/request process groups; only the controller owner performs final audit teardown. The current listener has no default 30-second header timeout, matching the frozen Axum/Hyper timer configuration.

The source and exact image/evidence hashes are recorded in HIA_NATIVE_HTTP_OWNER_CHECKPOINT.json. Python authoring and qualification drivers are development tools; every product policy in this checkpoint is emitted HIA and the syscall adapter is the explicit mechanical assembly boundary.
