The returned owner receipt must equal the actual raw receipt plus exactly the original two return fields. The request must bind the original owner implementation SHA, exact argv/cwd/environment, deadline-started=180e9, 180/3 limits and cleanup with ECHILD, no remaining children, deadline error or cleanup error. The first owner, test, source/runtime/control guard, frame readback, cleanup or publication failure stops all later stages. No retry, fallback directory, source regeneration, swallowed assertion or automatic remapping is provided. Every stage still attempts terminal guards and evidence readback; failures are preserved rather than converted to success. The outer recorder records actual process exit but cannot grant product qualification or infer a missing owner receipt. On an interrupted outer with uncertain descendants it retains an explicit hold; it does not kill a subreaper first and assert cleanup.

The source/controls, VM limits, source recovery gaps, original failures and remaining foreign providers are explicit. This is only an explicit selected op13 policy route.
